# C35 paired controller source seam

Status: source only. This directory is not a physical GO, a learned policy, or a claim of two-support feasibility. `core35.py` has no plant/model import; `adapter35.py` uses the existing Fast scratch and returns one torque vector for the caller's one real control. Root owns construction, actual five-native evidence, archiving, budgets and the only execution.

`PairController35(plant, side_access=None)` exposes `start(command, sensed)`, `set_command(command)`, `set_evidence(sensed)`, `compute()`, `reset()`, `status`, `done`, `last_record` and `swing_legs`. Root attaches its access fence as `side.access = access`. The worker publishes a `Command35(vy_mps, gait_enabled, issued_control_index, expires_control_index, stop_kind)` and one `Sensed35` for each actual control. The latter carries the actual body/COM state, **wheel-body center** anchors and separate whole-wheel contact points, complete-wheel minima, current contact/load, previous five-native contact-free and pair-load evidence, and post-state stop metrics. Paired IK targets the body centers while preserving Fast's per-wheel collision-shape Z correction. A case can begin at any global control index; later indices must be contiguous.

The core owns one reference clock and one alternating pair schedule. Its .25 s quintic velocity Hermite segment preserves velocity, acceleration and jerk when release/cancel interrupts a ramp; body position is its analytic integral. It emits simultaneous four-foot world targets, two-foot reference velocity, pair phase, raw/projected/consumed landing XY, load weights and stop state. Stance anchors stay fixed in world coordinates; only the two returning feet receive measured new anchors. Transfer unloads the intended pair over .06 s. Release during transfer enters a .06 s `transfer_restore` from the last consumed weight, with all four wheels loaded and no new lift. Release during an airborne pair completes touchdown, dwell and load before 50 stable all-four-contact observations with **origin** speed below .010 m/s allow handoff. Reversal requests stop first and never launch an opposite pair in this pilot. At most 16 completed pair exchanges are admitted.

The adapter reuses Fast `_geometry`, `_com` and `_allocate`, original wheel-brake arithmetic and actuator limits. Its new `_paired_targets35` performs **one** scratch solve with both swing Z offsets preserved in every outer IK pass; the old single-leg `_ik` resets other Z targets and cannot be composed twice. It gives both named legs swing PD and one coupled 6×6 inertia term from a single counted fullM; all other legs retain stance PD. The original 4 rad/s and 60 rad/s² joint-target clips and 16 actuator torque clips remain. `last_record.calculation` keeps pre-state, final targets, Jacobians, inertia, allocation, bias, preclip and clipped torque for independent reconstruction. `last_record.reference` exposes exact consumed phase masks and the common horizontal trajectory. Its native horizontal gate covers the current nonzero foot-reference velocity and the next control for the same pair, including the first lower control; the cancel trigger uses current nonzero velocity only. `last_record.pair_events` records each actual completed pair.

`support_mode='pair'` names two stance wheels throughout lift, horizontal, lower, probe and dwell; all other phases use all four. The root native recorder must validate every native substep against the saved consumed mask, including actual per-stance contact/load and summed normal force. A controller reference, scratch force or Fast dynamic-margin proxy cannot substitute for actual contact reaction. The adapter rejects reference speed above .030 m/s, reference acceleration-height budget above .015 m, final paired IK error above .008 m and any nonfinite target/torque. Hard native/reference faults immediately stop physical execution and prohibit B22 handoff; only normal release/cancel follows the controlled touchdown and stop path.
