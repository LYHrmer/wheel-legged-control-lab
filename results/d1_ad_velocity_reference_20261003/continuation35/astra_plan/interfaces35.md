# C35 source interfaces (no execution GO)

Authoritative design: contract35.json; this interface clarifies command interpolation and schema joins before any source GO. Root alone executes all future checks and physics.

`Command35` contains `vy_mps`, `gait_enabled`, `issued_control_index`, `expires_control_index`, `stop_kind` (`none/release/cancel/expired/conflict`). Allowed raw vy is −.025/0/.025; direction is derived, not substituted for the real velocity. The in-place case intentionally enables gait at zero velocity. The worker publishes one fresh command for every actual side control, and records any synthesized expiry/stop reason. TTL is20 controls. GUI remains unchanged by this pilot.

Command interpolation is a **quintic Hermite polynomial in velocity** lasting .25s. At a new command it starts from the currently consumed velocity and its first two derivatives, and ends at the new raw velocity with zero first and second derivatives. Thus cancellation during the initial ramp preserves velocity, acceleration and jerk continuity; do not restart a smoothstep assuming the current derivatives were zero. Body acceleration is the analytic velocity derivative; body position is the analytic integral, never a second, independently advancing clock. The fixed pulse with completed start and release ramps integrates to exactly .150m. Absolute smoothed reference speed may briefly exceed the raw target during a derivative-continuous cancellation, but must stay ≤.030m/s; reference acceleration×actual COM height/g must stay within .015m. Exceeding either is a declared controller failure, not an unnoticed clip or new experiment.

`Sensed35` is an immutable input snapshot: current control and native range, actual base pose/quaternion/qvel/COM velocity/whole COM, actual four contact points and complete-wheel minima, per-wheel true contact and positive normal sums, previous complete5-native contact-free masks and minimum shape values, compiled mass/limits and current force evidence. It contains no future state or engine handle. Current and previous provenance indices must be explicit.

`Reference35` contains before/after phase, current stance/swing pair masks, full body position/velocity/acceleration, all four world foot targets and derivatives, allocation weights, raw/projected/consumed landing targets, pair-local elapsed/duration/origin/span, stop state, handoff flag and failure reason. Core35.step consumes exactly one real .01s control; no plant.step or extra time advance. At phase boundaries the consumed reference and declared masks name the same control. Stance anchors update only on actual qualified touchdown; a new pair begins only after returning all4 support. Cap16 completed pair exchanges per session.

Controller adapter uses one original plant and side scratch. Its paired IK must preserve raised Z targets for both swing legs in the *same* solution. Retain the original per-wheel geometric correction for real collision shape and joint-range checks. New compute applies swing PD and coupled6x6 inertia to the explicit moving set; fixed-leg PD, force allocation and wheel brake retain their original arithmetic. New fields carry a `d1-c35-continuous-side-control-v1` identity; no false C27/C34 single-leg schema claim. FullM, Jacobians, bias, preclip and actual actuator torques remain recorded for an independent reconstruction.

Root35 case order is fixed by contract. Every case resets the same persistent plant/controller once, then performs exactly200 B22 controls, one continuous side session≤1200 controls, and exactly400 B22 controls after qualified all4 handoff. Side time includes the active command, pending foot completion and stop stabilization. Original tail check uses last100 retention controls. Cancel triggers at the next control after the first actually consumed horizontal reference velocity of either swing leg; it does not use a future planned tick. No complete side session may exceed1800 total controls. Root records attempted versus successfully closed cases separately, including all consumed partial work on failure.

No training/learning_cycle alias is needed. Controls/native/state arrays keep the established native archive format plus clearly named `controller_record35`, `skill35` and `pair_events35` extensions. Root and readers must agree a small actual synthetic receipt fixture before source freeze; do not guess field paths after physics.

Contact frame/local wrench provenance follows the immutable native recorder. The independent reader reconstructs these from original contact slots and compiled state; commands, allocation forces and scratch geometry are never substitutes for actual reactions.
