# C35 持键连续侧移：接口设计（非执行合同）

**建议唯一主线：**把 A/D 变成有时效的横向**目标速度**，由一个连续侧移调度器独占传统侧移扭矩，在单腿支撑/摆动循环中连续更新身体和足端参考；只有安全停稳后才交还 B22。这需要新任务和独立证据，不能把现有 ±30/40 mm 单次宏的成功外推为连续能力。本文仅只读源码；C34 闭合后再决定是否进入新合同。

当前入口是 [InputController27](/home/lyh/wheel-legged-control-lab-work/recovery-20260912/stability_20260924_full_drive01/continuation27/sol27/input27.py:62) 从 A/D 的 held/press 生成离散 `side_direction`，而 [CourseSideStepIntent](/home/lyh/wheel-legged-control-lab/scripts/d1_course_side_intent.py:151) 把松键解释为“完成已承诺的一整周期、停止下一次重复”。[GUI owner](/home/lyh/wheel-legged-control-lab-work/recovery-20260912/stability_20260924_full_drive01/continuation27/root27/run_gui27.py:685) 每个控制步将该方向绑定一次预览，并在侧移时给 B22 精确零 action16。[Hybrid](/home/lyh/wheel-legged-control-lab-work/recovery-20260912/stability_20260924_full_drive01/continuation27/sol27/hybrid_adapter27.py:232) 又限制一次 accepted start、固定调用 30 mm；完成后下一次 preview 才重置轮系控制记忆并还给 B22。旧 [99D 编码器](/home/lyh/wheel-legged-control-lab/runtime/d1_b22/research/course_impl08/full_drive_observation_08.py:145) 拒绝非零 `lateral_velocity_mps`。因此最小接缝是：GUI/Input 产出带时间戳的 `desired_vy` 与 stop/reverse 状态，Hybrid 在同一 preview/compute 对上以**独立侧移意图通道**交给连续侧移调度器；侧移期间仍给 B22 零 action16，普通 forward/yaw 命令保持零，绝不伪造 B22 已学会 vy。旧 30 mm `Fast.start`、四腿完成即 `done`、1500 次 side compute 与单次启动限制要由新连续会话语义取代，不能循环调用四腿宏来冒充连续控制。

持 A/D：新鲜、单向按键持续给同号受限速度目标，不在每个 30 mm 边界重启、重置模型或交权。松键或 A+D 同按：目标变零，不立即移交；调度器完成当前单脚安全落地、制动/回中、四足承载与速度停稳后交权。反向键：先走同一减速/落地/停稳边界，再在仍有效的反向持键下重新准入；不排队未来反向脉冲。X、失焦、输入 TTL 失效和跌倒恢复走高优先级受控取消与 release barrier，不能当作普通松键。[Hybrid 的 handoff](/home/lyh/wheel-legged-control-lab-work/recovery-20260912/stability_20260924_full_drive01/continuation27/sol27/hybrid_adapter27.py:202) 仅在最终传统侧移扭矩被消耗、四足接触且无待完成脚动作后，于下一次既有 preview 重置轮系记忆；B22 之后才恢复预测。连续行进中由单一侧移 owner 做多腿顺序规划与身体/足端同步参考，按真实速度、支撑裕度、接触和剩余停止距离决定下一个脚相；状态相关策略若加入，也只选该调度器允许的参考速度/相位进度，不拥有 plant step、接触判定或扭矩限幅。

**安全边界：**原五个 native 子步/控制、单腿摆动时三足接触、摆动轮整体几何 clearance 与上一完整 native 区间无接触、IK/关节范围、姿态/高度/关节速度故障门、非轮碰撞、接触载荷、力分配及电机扭矩裁剪、异常时安全落地，均应逐步保留并独立重核（[Fast._advance/compute](/home/lyh/wheel-legged-control-lab/scripts/d1_fast_side_step.py:449)，[C31 native 横移核](/home/lyh/wheel-legged-control-lab-work/recovery-20260912/stability_20260924_full_drive01/continuation31/root31/record31.py:178)）。原 `shift` 的名义时间＋四足接触＋`>0.02 m` 动态裕度＋`<0.06 m/s` 低速 READY、`load` 的低速再启动及 `recenter` 停稳，是**单次准静态宏的排程/准入规则**；若连续运动跨离地而替换低速或等待条件，就必须逐项声明新阈值与 native 接触/反力/整轮扫掠证据，不能声称原资格原样继承。原 dynamic margin 用参考身体加速度代理，不是真实 CoP 证明。新任务需分别评估持键段目标/实际横向速度与净位移、松键/反向响应和停止距离、全程接触与支撑、失败/取消交权；质量、成本和保留门仍需同权限强 fixed 比较器。最小 fixed 路线是在这**同一连续输入、同步调度、投影/限幅权限**内先用确定的速度—支撑—脚相反馈规则，证明双向持键、反向、松键、异常取消的完整安全轨迹；只有其后仍有真实状态依赖的决策余量，才讨论 RL。
