# 第一次人工侧移试驾：体验未通过

用户反馈为“整体运行慢、W 不能直接过台阶、跳跃太矮”，并要求增加 Shift 加速。这里把人工体验记录为未通过，保持原始 `summary.json` 不变；GUI07 的自动通过不覆盖这次人工反馈。

本次由 root 直接启动桌面 normal 画质窗口，未运行自动按键 harness。GLFW 记录了 7172 个控制拍、71.72 仿真秒、78.96 墙钟秒，窗口关闭后正常归档。一段连续轨迹、没有 R 或区域重置、没有 A 按键，也没有失焦事件。仅凭键盘事件文件不能识别具体操作人或排除所有外部事件来源，因此“未脚本注入”依赖已记录的启动操作，而非从按键频率推断。

8 份原始文件和 49 份归档源码的 SHA256 全部匹配。所有 qpos/qvel/16 通道扭矩有限，每拍实际状态时间增加 0.01 秒；模型物理步长 0.002 秒。独立分析只加载新的 MjModel/MjData 并做 `mj_forward`，没有推进原始仿真或修改记录。
