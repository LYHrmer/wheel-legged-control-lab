# 同底座共享动作与独立动作：三训练种子对照

两个策略都使用同一个轮腿低层控制器。`shared2` 同步调整四腿伸缩和四轮速度，
`independent8` 允许逐腿、逐轮调整。观测、奖励、物理动作尺度及反馈增益共用，
没有把旧两维力残差控制器混进本次比较。

六模型各训练 32768 次环境转移，共 196608 次。固定预算结束后直接评测，不挑最佳
checkpoint，不按留出结果换种子。20 条命令全部结束，总耗时 2064.99 s；
70 项训练源码前后哈希一致。这些是运行状态，性能见下表。

## 完成与质量

每格为四个案例中的计数：两条道路 × 两个 reset 种子。零残差每个 split 只运行一份，
不是三个训练重复。完整案例运行 60 s；质量还要求速度、yaw、高度与姿态 RMSE
分别不超过 0.08 m/s、0.08 rad/s、0.025 m、0.15 rad。地形曝光另行记录，不在质量门槛中。

| 策略 / 训练 seed | 开发完成 | 开发达标 | 留出完成 | 留出达标 |
|---|---:|---:|---:|---:|
| 零残差，无训练 | 4/4 | 4/4 | 4/4 | 4/4 |
| shared2 / 31000 | 4/4 | 4/4 | 4/4 | 4/4 |
| shared2 / 32000 | 4/4 | 4/4 | 4/4 | 4/4 |
| shared2 / 33000 | 2/4 | 0/4 | 4/4 | 0/4 |
| independent8 / 31000 | 4/4 | 4/4 | 4/4 | 4/4 |
| independent8 / 32000 | 4/4 | 4/4 | 4/4 | 4/4 |
| independent8 / 33000 | 4/4 | 4/4 | 4/4 | 4/4 |

shared2 / 33000 的开发集 road0 两例分别在 59.95 s、59.81 s 以 `map_boundary`
结束，保留失败，不能算作 60 s 完成。其四个留出案例虽然完整运行，速度误差仍越过
质量阈值。全部 56 例中完成 54 例、达标 48 例，没有删掉不达标记录。

## 留出指标

以下每行是同一模型四个完整留出案例的均值。没有混合不同训练 seed 估计置信区间，
也没有把控制拍当作独立重复。全部开发和逐例数据见[独立分析](../d1_shared_action_analysis/analysis.json)。

| 策略 / seed | 速度 RMSE (m/s) | yaw RMSE (rad/s) | 高度 RMSE (m) | 姿态 RMSE (rad) | 机械活动量 (W) |
|---|---:|---:|---:|---:|---:|
| 零残差 | 0.034730 | 0.039583 | 0.009306 | 0.028168 | 15.154 |
| shared2 / 31000 | 0.068725 | 0.038740 | 0.009596 | 0.030037 | 17.137 |
| shared2 / 32000 | 0.045215 | 0.038766 | 0.015527 | 0.036589 | 15.929 |
| shared2 / 33000 | 0.085976 | 0.038416 | 0.007829 | 0.029541 | 17.680 |
| independent8 / 31000 | 0.032897 | 0.040847 | 0.013975 | 0.040292 | 16.550 |
| independent8 / 32000 | 0.052774 | 0.047132 | 0.006320 | 0.051368 | 27.754 |
| independent8 / 33000 | 0.032405 | 0.036136 | 0.014484 | 0.035343 | 15.436 |

机械活动量沿用逐拍 `sum(abs(torque * joint_velocity))` 的时间均值，未建电机效率或再生制动，
不能当作电池功耗。shared2 / independent8 的归一化动作均方也没有能量单位。

八维策略在 31000、33000 上的留出速度误差低于共享策略，在 32000 上更高。
与零残差相比，八维的 31000、33000 有小幅速度改善，但高度、姿态误差和机械活动量更高；
32000 的速度更差，机械活动量也明显增加。三个共享策略的留出速度误差均高于零残差。
本轮支持“动作结构会影响小预算训练的结果”，不支持“八维必然更好”或“加 RL 总能胜过基线”。

## 怎样复算

原始 CSV、NPZ、源码归档从 [v0.7.0 下载说明](../../docs/reproducibility.md#v070下载与复算)
恢复后，使用修复了目录迁移校验的分析器，输出必须是新目录：

```bash
python scripts/analyze_d1_shared_actions.py results/d1_shared_action_study \
  --output results/my_shared_action_analysis
```

若数据恢复在别处，将输入换成那个实际目录，不修改记录中的原始绝对路径。
分析器核对这些原路径所声明的模型对应关系，再对当前位置的实际文件检查 SHA-256；
不需要原训练机器仍存在，也不加载 checkpoint。

六模型共保存 384 次 PPO `train()` 调用的数学记录，全部通过 GAE、高斯 log probability
和概率比复算。每份只抽取 env-major 顺序的前 128 个样本，不能称为全部优化器步骤重放，
更不是 384 个独立实验。二输出策略的总参数量为 19141，八输出为 19537；
除动作相关结构外，输出层也多出 396 项参数。

完整条件见 [protocol.json](protocol.json)，运行状态见 [summary.json](summary.json)，
源码与结束检查见 [source.json](source.json)、[source_consistency.json](source_consistency.json)。
各子目录保留当时的协议、模型和指标；本说明在运行结束后添加。
动作广播、两维概率手算和实验命令见[学习文档](../../docs/shared_action_learning_lab.md)。

这里只评测已知布局族的新地形参数实例，仍使用既有命令脚本，未测未知地形族。
同训练 seed 不保证两策略经历相同状态或重置时刻。本次没有域随机化或测量延迟，
不能替代已有延迟失败矩阵，也没有真机、跳跃或人工键盘验收结论。
