## 共同轮速残差是优先检查的直接通路

| 任务 | 平均轮速残差（rad/s） | 乘轮半径 0.087 后（m/s） | 实际额外均偏速 policy−zero（m/s） |
|---|---:|---:|---:|
| flat 0.6 | 0.12404 | 0.01079 | 0.01063 |
| flat 1.6 | 0.25014 | 0.02176 | 0.02160 |
| flat 1.2 + yaw | 0.20492 | 0.01783 | 0.01545 |
| bumps 0.4 | 0.09299 | 0.00809 | 0.00818 |

原控制器在身体前向 P 反馈生效、轮速目标未裁剪时，平均轮 P 项可精确化简为：`Kp × (mean(nominal wheel target + wheel residual) − COM vx / radius)`。正的共同轮速残差直接改变这个 P 项的目标。三个直行场的量级很接近实测额外偏速；名义轮速变化对应的速度量级仅约 10⁻⁵ m/s。

这些证据支持优先检查共同轮速残差，但不是删除残差后的反事实物理实验：腿姿态、接触和反馈也同时变化。不能直接把常量减掉，或宣称已找到训练退化的唯一原因。

保持窗口内，位置、轮速目标、力矩及保护裁剪比例均为零。记录中的 joint rate mask 平均为 0.25；它位于轮关节位置目标重置和轮 leg-PD 清零之前。抽查 flat1p6 tick600 的四个 true 位恰为轮关节索引 3/7/11/15，后续 wheel leg-PD 均为零，不能把这个中间 mask 当作 25% 有效动作被保护层抹掉。

## 当前证据不支持直接改奖励或增加训练

四个已评估任务的 drive 平均 reward 均降低：约 −0.00468、−0.01356、−0.01192、−0.00292。跟踪损失抵消了小幅高度奖励改善；在这些保存的评估状态上，没有“总奖励偏好稳态超速”的证据。此结论不代表整个训练分布。

完整训练的每步 reward 均值 3.94358；65 个闭合 1000-step episode 的零尾折扣奖励和均值约 397.922。该值仅用于说明尺度，**不是 PPO 的历史 GAE/bootstrap target**。final zip 内可读 JSON 配置为 gamma=0.99、gae_lambda=0.95、vf_coef=0.5、max_grad_norm=0.5、target_kl=None；读取 JSON 没有反序列化或加载策略。

历史 value loss 中位数 3573.94、EV 中位数 −0.001741，全局裁剪后的梯度范数约 0.5。没有保存历史 preclip actor/value 梯度、逐 minibatch value 或 bootstrap value，因此不能由此断言 critic 梯度挤压 actor，更不能伪造历史 PPO loss 重算。

下一研究候选先用冻结 final 和固定训练内窗口进行零物理的 value/梯度尺度审计，单独计模型前向和 backward 次数，禁止 optimizer/learn/save。其目标来自保存行为轨迹加当前 final bootstrap，不是 final 的真实 on-policy return。只有得到区分假设的证据后，才另立一次单因素学习合同；不重复 65,536 步，不同时改奖励、课程、网络和学习率。
