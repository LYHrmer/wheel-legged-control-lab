## 最终结论

限定高斯均值的四轮共同分量后，三个训练种子中有两个的最终场景平均速度误差下降，第三个退化。原版 PPO 跑满 1/6 个模型与场景组合，候选跑满 2/6；零残差基础控制器跑满两个场景。48001 和 48003 的候选均有更早越界。**没有满足三个种子一致改善的预声明条件，不采纳为驾驶默认策略。**

| 种子 | 原版速度 RMSE | 候选速度 RMSE | 原版/候选跑满回合数 |
| --- | ---: | ---: | ---: |
| 48001 | 0.043521 | 0.039743 | 0/2，0/2 |
| 48002 | 0.196228 | 0.123295 | 1/2，2/2 |
| 48003 | 0.047161 | 0.058641 | 0/2，0/2 |

单位为 m/s，两个最终场景等权。各模型实际运行时长不同，完整结果和每个种子三方相同前缀的诊断分别见 [comparison_final_01/comparison.md](comparison_final_01/comparison.md)。未补齐提前终止后的缺测数据，也未删除终止罚分。相同时长仍可能走过不同地形。

零残差的平均速度 RMSE 为 0.042510，平均回报 60.641086。它每个场景只运行一次，分析表重复展示的是同一参照。新策略的数学约束正确、全量测试通过，不代表任务效果得到提升。GUI 跳跃、横移和大台阶未在本任务中训练。
