## 证据与比较成立的范围

A 是 C20 唯一完整 A1，32768 controls；本轮不重训 A。B 从同一 C15 grouped 父模型和 Adam 起点重新训练一次 32768 controls，未接续失败的 B20。B 的唯一完整末端 checkpoint 在开发与最终分数出现前已经固定，未挑 checkpoint、未续训、未补步。A 复用桥、首 1024 个控制间隔的 64 项逐位配对均通过；初始五数组及 PI/z、servo、provider、previous-action 等完整控制 reset 同态得到核验。新场逐 actor 的初态/隐状态配对及旧七复用链也完整。

A/B 共同使用 target_kl=.03、批 KL>.045 的正常早停规则及同一硬失败条件。A 实际 351 次 optimizer、373 次 evaluated minibatch、101 entered epochs；B 为 355、377、104，各有 22 次正常 KL 早停。比较对应同一控制预算和公共优化规则，不能称为实际 optimizer 次数相同的消融。B 的训练、学习、全 tick 归档、原生 5T 链、九项奖励、有效覆盖读回均通过。每个 post-warmup 槽有 3 个完整有效 episode；规定 yaw 两符号端点各累计 171 ticks，bumps/ramp/rough 有效载荷 episode 数为 3/6/3；33 次实际 reset 几何桥接通过，包括原失败位置 source18。

C21 完整有限预检保存为失败：160 个训练 schedule 通过，16 个评估中 4 个 yaw 不通过。C22 保留历史失败，只对这四个 yaw 做预先指定的 100/200/100 时序修正并执行 6400 个纯 servo 间隔，四条均通过。其余 172 条资格与原始命令/模板按来源复用。C20 B18 是 raw 净 yaw 为零而 servo 净航向为 −.10416 rad；C21 四条旧评估是 raw 与 servo 净航向本来就为 ±.240/±.224 rad。两次失败机制不同，均没有被改写成训练假设失败，也没有把名义路径当机器人轨迹。

开发集只给描述性分数，最终执行资格不依据收益或覆盖择优取消。固定最终四场×四 actor 全部执行，16/16 完整、安全、任务通过。原七、开发四、最终四中，A/B 各全部通过；zero/old 的原七采用已核 C18 记录复用，新八场均实际完成。封存最终分数没有回写训练或开发合同。

原六继续按原 raw pooled SSE/成本判 RL 贡献，mirror 不入分母。B/zero SSE=59.921959806592746/57.6856196394755=1.0387677238，超过 .85 门；只有 rough 一对满足单对≤1.02，合计 1/6，未达到四对；没有 zero 失败而 B 通过的能力转换。成本比 1.0406938069 虽通过≤1.20，贡献总门仍为 false。A 同样 false：pooled SSE 比 1.0773642198、2/6 单对不差、无转换，成本比 1.1713358386。能力脚本全部通过与 RL 增益不足可以同时成立。

可发布的正向结论是：**在这一共同起点、同一确定性 oracle/模型及预列有限命令组合上，B 命令/时序课程组合优于原课程 A 和旧策略。** 不能分别归因于速度或时序中的单一因素，不能据此声称 RL 已超过基控、多 seed 统计可靠性、真实物理随机化、任意命令泛化或自由键盘驾驶资格。seed 标签仍不是独立物理随机化。最终 1.1 m/s、.28 rad/s 等保留组合通过是有限组合证据。

## 下一步的有限顺序

1. **结束这条扩训分支，冻结 B22 为下一工程候选。** 唯一模型身份见下表；当前默认策略保持现状。本轮课程假设已有判定，不因 RL 对 zero 未过就追加同课程 PPO、换 seed、挑 checkpoint 或再跑旧批次。RL 成为核心贡献的长期目标仍未完成。
2. **先交付当前 99D/16D 实际策略的可用 GUI。** 用固定 B22、同一 C18 基控与观测/动作接口集成；清晰显示实际载入模型和 RL/zero 模式，完成输入焦点、失焦/退出、释放减速、停止及 reset 的有界资格。旧85D/13接口 GUI 不能直接代表当前策略；脚本通过不代表自由键盘通过。GUI 可用交付与 RL 收益分别验收，不以收益门通过作为集成前提。R 仍仅为仿真 reset，不是摔倒自恢复。
3. **随后过独立的真实15 mm单台阶物理闸。** 新合同先核确切 compiled 15 mm 几何、出生点/接近距离与完整越过退出时窗；固定 B22 和 zero 在同完整初态下配对，使用原生轮载荷、接触、全程姿态/clearance、完整通过及停稳证据。2400 ticks/.20 m/s 只是待核可容纳性的候选，不能自动升级为已执行预算。旧06旧策略15 mm通过和本轮bumps不能抵扣当前99D/16D资格。一次完整配对后按预注册门结案；若记录无效或模型/物理失败则停止，不现场降低台阶或无限重试。
4. **新训练只由该能力闸的实际缺口触发一个新假设。** B 失败而 zero 通过时先解决残差干扰；二者皆失败时先检查基础能力与任务可行性；B 通过而 zero 失败才有具体能力转换证据；二者皆通过仍须用预注册误差/成本门判断增益。现有结果不支持直接加大相同课程训练量。侧移、跳跃和进一步提速后置于越障/GUI资格；现有1.6 m/s固定脚本已覆盖“超过1.5”这一有限目标，不外推任意驾驶。

以上是下一执行合同的优先级，不新增本轮模型或物理额度，不修改09-30旧主方案、C20/C21/C22历史合同。
