## 2. 修复有效，但收益归属须分清

C17先分别检验了两项控制干预：已有yaw反馈的内部上限从±0.6放至±1.2、gain4不变；轮速积分共同分量改为body速度误差，避免坡道上body已超速时仍积累正共同积分。完整共同P通路原本含body速度反馈，问题不是“没有速度闭环”。两项定向任务通过后，C17组合资格仍只有6/7：rough grouped RMS 0.05339427199909047超过原0.05。该失败、原记录及全部开发成本保留。

C18先只读四条旧/新rough轨迹。新共同积分波动减小、body速度1–5Hz波动反而增大，主要回归段未触yaw或实际轮扭矩限幅；这些数据不支持“共同积分高频响应过强”的诊断。选择唯一候选，对共同wheel/body误差差值做一阶滤波：

```
ew = clipped_wheel_target - measured_wheel_omega
eb = (servo_vx - pre_body_COM_vx) / 0.087
d = mean(ew) - eb
common active: z_after = z_before + (d - z_before)/21; eI = ew - z_after
common inactive: z_after = 0; eI = ew
reset: z = 0
```

dt=0.01s、tau=0.20s固定；没有扫描时间常数。该坐标修正在直流极限保留body反馈，对较快变化保留轮速积分响应；Ki3、积分±4Nm、P、差动、支撑和保护范围保持，退绕判断使用实际eI。4,000步开发先同时通过rough/ramp，再以相同冻结源码完成24,000步资格。最终rough RMS 0.04191901909011142恢复通过，坡道仍通过。

这支持所实施控制律干预的闭环效果。保存轨迹中的频谱关系没有独立证明每个中间机制；接触位置/时序及策略动作会随轨迹改变，不能将跨轨迹逐tick差值当作某通道的独立因果贡献。grouped权重从阶段15延续未变，基础控制修复收益不计为PPO训练进步。
