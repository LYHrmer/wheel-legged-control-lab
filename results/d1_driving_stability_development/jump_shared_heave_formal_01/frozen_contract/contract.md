# Shared-heave environment, checkpoint and one fresh PPO experiment

Decision: **GO for one bounded new mechanism experiment after the zero-integration interface gate below passes.** The completed local qualification reproduced 489 zero-action states exactly across 1449 independent controller calls. Shared input changed leg torque, peak safe leg torque was 49.884205 Nm, and no torque protection fired. There were 2573 mj_forward calls from construction/IK, but mj_step/mj_step1/mj_step2 were all zero. Extension-domain and joint-target clipping occurred and remain unchanged. This supports an executable action interface, not 20 mm reachability or stability certification. The previous failed policy and all frozen sources/records remain intact.

Its `unwrapped` is itself. Expose Box(-1,1,shape=(1,)) and the unchanged 95-dimensional observation space. Delegate `reset`, `configure_next_episode`, `close` and required diagnostics explicitly; read-only attribute fallback is allowed for existing inspection APIs, never automatic write-through or hidden step/reset. Construction/reset/preview are nonintegrating. Make inner ownership and its old identity explicit in metadata rather than pretending the inner itself acquired the wrapper identity.

For each `step(action1)`, snapshot the current executed tick and current episode request tick before calling the already qualified `map_heave_action`. Call `inner.step(physical8)` exactly once. Return its observation, reward, termination and truncation unchanged; annotate a copied info with policy input, clipped scalar, applied physical8 and the consumed gate snapshot. Do not recompute reward. Existing previous-action fields, reward action-change term and physical controller input remain the genuine eight-vector. Preserve PI/target/previous-action memory at request boundaries; zero masking does not erase prior dynamics. At an inner exception preserve failure/partial counters and never retry that tick. Training logs must distinguish scalar policy actions from physical eight-actions and actual leg clipping from all-16 flags.

The sole mechanism is `d1-jump-shared-heave-window-v1`: [c,c,c,c,0,0,0,0] for s <= k < s+120, zero otherwise. Keep original 0.04 m scale, original controller/limits/raw height profile/reward/geometry/scoring. New outer task identity: `d1-native-plane-shared-heave-hop-task-v1`. Observation contents and schema remain `d1-jump-oracle-task95-v1`; action and outer task identities distinguish the new semantics. The static outer config contains the full unchanged inner jump config plus exact action metadata. Episode index/seed/current curriculum goal/progress are runtime receipts, not mutable checkpoint compatibility criteria.

## Own strict sidecar; do not call the old gather loader/writer

Provide independent writer/loader functions, for example `write_heave_checkpoint(model_path, metadata_path, env, *, extra=None)` and `load_heave_policy(model_path, metadata_path, env)`. New sidecar schema: `d1-jump-shared-heave-checkpoint-v1`. Required identity includes model SHA256, outer task, exact observation/Box definitions and dimensions (95/1/8), canonical ordered physical channels, full 8x1 matrix, the complete integer-window gate including its no-reset behavior, scales, inner static task/controller/plant/terrain/state-source identity and configuration, and source identity. Existing old gather fields are not a substitute; reject them as an incompatible sidecar family. Extras cannot replace reserved identity fields.

Before any `PPO.load`, parse/type-check and compare the complete identity with the supplied wrapper, check model hash, and reject missing/old schema, eight-action checkpoints, changed matrix/wheel zeros/window/order/scales/config and nonfinite numbers. Use strict canonical types (booleans are not integer dimensions; reject malformed/duplicate identity keys). Only then deserialize with `env=None`, so no env reset is requested. Check loaded action/observation spaces and policy dimensions; prediction on saved observations must agree with the pre-save model. Loader calls neither the legacy gather loader nor any rollout verifier. Subsequent inference/training is an explicit caller operation.

Pure instrumented-inner tests verify: one inner call per step; gate ticks s-1,s,s+119,s+120 for s=175/225; previous physical action and PI not cleared; malformed action rejection before inner call; 95 observations/reward/terminal fields preserved; inner exception not retried; wrapper unwrapped/attribute/config identity cannot fall back to old gather metadata. Use small newly constructed untrained one-action PPO to save/reload/predict fixed saved observations with bitwise parameter/action agreement and no learn/reset/step during reload. Test a correct round trip plus changed matrix, gate, family/schema, parent config, model hash and 8-dimensional model/sidecar. This gate is complete env/loader interface qualification, separate from the already passed local algebra qualification.
