# 下一资格合同：直接 body-rate 误差替换的零物理审查

本合同记录一次已执行、固定预算的资格审查，不授权实现或物理试验。最终结论：**代数与单拍幅值检查 PASS；直接替换进入控制实现/物理 NO-GO**。剩余机械与采样证据未完成，不把它写成已通过。

## 唯一被审查对象

只审查“将 wheel PI 的差动 yaw 误差直接替换为机身 yaw-rate 误差”。本次没有实现该控制器，也没有 full-contact、腿阻尼或新增增益备选。它与现有 center 补偿是替换关系，不能叠加。若未来被重新论证，其 gate 仍只能是当前 raw `v == 0 && yaw != 0` 的原 50 拍 pulse，不加 latch、不改命令或评分。

设轮横向位置向量为 y，y0=y−mean(y)，S=y0ᵀy0，R=0.087 m，实测轮速为 ω，实际机身角速度为 r_body，原有截断后的机身目标为 r_eff。被审查的代数为：

```
r_w = −R y0ᵀω / S
ω_base = (v − r_eff y) / R
Δω_target = y0 (r_body − r_w) / R
ω_target = original_clip(ω_base + Δω_target, ±30)
```

未截断时，`−R y0ᵀ(ω_target−ω)/S = r_eff−r_body` 且 mean(Δω_target)=0。系数 1 来自此恒等式；没有经验选取反馈系数。原 wheel PI Kp=2.2、Ki=3、dt=0.01 s、积分限制与保护保持原值，仅作独立单拍影子计算。

## 固定输入、预算和执行

输入固定为 `flat_plane_02` 与 `plane_turn_center_01` 各自 left/right 两条保存轨迹，共 4 条；每条只取决策 pre-step tick 200..249，合计 **200 个独立代数样本**。旧输入 SHA 和原报告 SHA 逐项验证，结束后再次检查。每一拍使用其自身保存的积分记忆，不把影子积分递推到下一拍。

预算：0 个物理积分步骤、0 次 controller compute、0 次新接触求解、0 个新训练/模型调用、0 个参数扫描。已执行脚本 `qualify_body_rate.py`；实际输出 `body_rate_qualification.json`。可执行复算命令在 README，输出必须写到全新路径。根代理已独立执行并得到相同 SHA。

## 实际核验及判定

1. 200 个样本全部满足未截断 yaw 误差恒等式，最大残差 3.34e−16 rad/s，共模增量最大 2.23e−16 rad/s。
2. 所有样本均未触发 ±30 rad/s 目标截断、原积分截断/拒绝或 12 Nm wheel 请求界限。最坏单拍影子请求为 4.122049 Nm。它只能说明这些保存状态的单拍幅值，不说明新闭环会留在这些状态附近。
3. 固定机身角速度，只施加差动轮速变化 `δω=y0/R` 时，有 `δr_w=−1`，故 `δω_target=y0/R`，于是 `δ(ω_target−ω)=0`。实算导数范数最大 2.04e−15。直接替换精确删除了原 wheel PI 对这一纯差动自转扰动的比例反馈及本拍积分增量反馈。
4. 本合同要求保留原差动轮速阻尼，或有独立机械/采样证据足以论证其变化。当前第 3 项已经违反“原样保留”；后者没有证据。因而结论为 **NO-GO**，不能因为前两项通过而进入物理。

这不是“该系统已被证明不稳定”。被动关节阻尼、摩擦与接触约束仍可能影响该模式，但现有代数核验没有量化它们，也没有建立装载/弱接触/离地情况下的闭环采样稳定性。不要用未测的阻尼或假定无滑接触补全证据。

## 唯一后续入口与未完成部分

当前直接替换对象已经被本次资格审查否决，不继续对它调系数或扫参数。根代理已另行委托独立代理做“保留现有差动轮速反馈时，真实接触几何与控制作用能否形成可实现的 yaw 通道”的 0 物理机械/采样审查。本目录只规定其验收边界，不声称该工作已执行，也不提前选择新机制：

- 必须从实际 wheel PI、腿控制和保护顺序出发，显式给出纯差动轮速扰动下的闭环反馈导数，证明保留原 wheel PI 的速度阻尼；不得用另加经验 gain 抵消本合同指出的问题。
- 必须把接触点完整 Jacobian、轮架角运动和横向接触力矩的可实现性纳入同一物理框架；center 纵向恒等式不足以证明任意 yaw 目标可实现。保存 endpoint 与 native cache 的相位不可混用。
- 必须给出真实结构导出的参数/带宽来源和 dt=0.01 s、原 PI 积分及保护后的采样检查。没有这些来源时，输出应是“证据不足/NO-GO”，不能提交猜测增益的候选。
- 只有形成一个明确的单机制候选、上述必要证据闭合且原始评分/安全边界不变，才可输出 GO 到**独立实现合同**；仍不自动授权新物理。任何反例、接触假设不成立或不可辨识的参数都输出 NO-GO 并标出所缺最小证据。

本轮未完成且不得外推：全状态闭环稳定性、接触切换鲁棒性、未来候选的原 G1 通过率、与 stop damper 的组合，以及跳跃/障碍/提速/物理自救。
