# 85 维直行训练链烟雾验证

`heading_smoke32_02` 和 `heading_smoke256_01` 均完成：实际训练分别 32、256 步，完整 PPO 更新分别 1、8 次。保存发生在 `PPO.train()` 返回之后；32/256 两个预算下的前 32 步参数哈希和课程暴露记录完全一致。

每个已保存模型均通过新任务 helper 重载、参数哈希和确定性动作一致性检查，并在独立环境额外执行一步。成功两次烟雾共 288 个训练转移、3 个独立重载物理转移；额外步骤未计入训练预算。

`heading_smoke32_01` 是保留的失败尝试：它完成了 32 步训练及保存，但训练后校验器尝试深复制带有非叶张量的 SB3 policy，触发 PyTorch 错误。后续改为重建 policy 并加载保存时的参数快照；训练算法没有因此改变。失败的协议、模型和失败记录均逐字节保留。

新增课程与 runner 的 15 项测试全部通过，ruff 通过；只读验证共 195 项，零失败。烟雾使用 32 步 rollout、32 batch、1 epoch，仅验证训练链，不能代表正式 128/128/4 设置下的学习质量。实际课程暴露只有 level 0；高阶段切换由独立调度单测覆盖，正式训练另有实际暴露记录。

此目录保存原始烟雾文件及 SHA manifest。`validation.json` 是只读核对结果，`local_integration.json` 记录修正和验证边界。正式三 seed 训练由根线程在烟雾通过后另行启动，不属于本目录结果。
