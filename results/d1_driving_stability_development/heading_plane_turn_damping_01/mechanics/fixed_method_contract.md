# 209 姿态、零物理的转向纵向阻尼资格合同

本合同先于数值检查冻结。它只授权离线保存态/模型代数，新增控制步、物理子步、训练步、控制器 compute 调用、接触力求解均为 **0**。当前原 5° heading peak 门槛仍失败；不更换 raw ±0.6 rad/s、200..249 拍脉冲及 0.3 rad 最终参考。

唯一待资格假设：原 flat-plane zero 控制器中，**只在 raw forward == 0 且 raw yaw != 0** 的执行拍，加入每腿 `δτ_i = −b Jx_iᵀ u_i`，`u_i = Jx_i qdot_leg_i`，`Jx_i = body_rotation[:,0]ᵀ J_center_i,leg`，固定 `b = 126.4374005337902 N·s/m`。其余执行拍严格透传。没有 latch，没有 center `+u/R`，没有停车阻尼叠加，没有新 wheel target、cap、PI gain、滤波或触发阈值。

该 b 仅复用原名义纵向模态导出的物理阻尼系数，不声称是 yaw 临界阻尼。旧 plane 停车 4000 步候选已通过是有边界的旁证，不替代本转向检查或新转向轨迹。

固定输入为 `flat_plane_02` 和 `plane_turn_center_01` 的左右 turn，四条记录各取 `S[199]、S[200..249]、S[250]`，共 **208 保存姿态**；另取原 baseline 左转 `S[0]` 名义初态 1 个，共 **209**。不增加样本、不扫描 b、不重跑轨迹。前者是原 baseline 上的实际候选资格；失败 center 姿态只作已见状态范围的代数压力检查，不是二机制组合候选。

固定离线方法：

1. 核对原 G1 协议、77 冻结输入及四条输入 manifest；以 kinematics/comPos/comVel/Jacobian 重建轮中心 body-x 相对速度。全部 scratch time 保持 0，积分/forward/inverse/collision 入口立即报错。
2. 用四维 u 在常数向量、去均值的轮横向坐标、正交余量上的分解，报告总平方和及左右差动份额。`δτ·qdot = −b Σu²` 是更新瞬时的精确恒等式，不是原生保持区间功、全机器人能量或因果占比。
3. 各保存状态只算一次 `original_unlimited + δτ`，再重算原 16 轴限矩/位置外向/速度外向保护；报告请求余量、保护变化、安全后的实际增量功和额定速度/位置边界。wheel 四轴增量必须为零，直接 wheel-spin 的原 PI 速度阻尼导数 `−(2.2 + 3×0.01)` 必须保留。
4. 用 crb/fullM 计算同姿态质量矩阵和 `D_new = b Jxᵀ Jx` 的自由惯量谱；报告 `0.01 λmax(M⁻¹D_new)` 及与简单原关节速度阻尼相加的辅助谱。它不含完整接触、刚度、原 PI 状态与外环耦合；数值大于标量显式纯阻尼阈值 2 是风险提示，不自动判定实际 loaded 闭环失败，也不据此改变 b/dt。
5. 用完整中心 Jacobian 构造单位 world-yaw、中心固定的虚位移模态，报告名义 Mθ/Kθ/Bθ 和同 b 的投影；检查新增力矩对该模态的符号。此投影不是实际外部净 yaw moment。
6. 在每个同期已存加载接触点，对原 ±0.6 纯 yaw 与原几何 wheel target，报告“腿冻结”时沿真实轮轴水平投影的侧向接触速度。另在每个轮的载荷加权代表点求唯一线性速度解：接触点速度为零且中心纵向腿速度为零，未知为该腿 3 关节与轮转速。保留其奇异值、关节速度、与原 wheel target 差、全部实际接触点残差。代表点可行不等于有限接触区域完全无滑移；这里不求接触力，不传播姿态，也不加入此速度解作为第二控制机制。

数值检查的判据是机制资格和风险定位：有限值/可复算恒等式、增量作用在目标反对称腿运动、轮 PI 阻尼保持、安全余量与实际关节速度不出现明显先验冲突。几何审计若显示完全冻结腿不容许无侧滑 yaw，则明确“仍需原腿侧向活动或接触侧滑”，不把它误作新 plant bug；若原腿侧向自由度也没有有界可行方向，优先停在零物理机械诊断。未知全局稳定性本身不否决有限开发探针。

本合同后最多建议一个独立有界物理证伪试验，**由 root 另行决定启动**：左右 turn 各 800 步，加正反 stop 各 800 步，合计 3200 新控制步 / 16000 子步；复用原 `flat_plane_02` 四条基线，不新跑 bypass。原 raw/gates 全不变。turn 执行 0..199、state/obs 0..200、1000 native 子步逐位相同（本项只改 torque，preview 目标未变）；stop 全 800/801 与完整原 summary 除 model 逐位相同。激活恰 200..249，250 恢复原控制；不因关闭后回摆改成 latch。

可证伪预测：若假设成立，pulse 的反对称中心纵向速度降低，body yaw 增量与原 raw peak heading 改善；同时必须观察实际 native 纵/侧向抵消力矩、支持接触和滑移。若只增大侧向抵消/滑移、body yaw 不增，或 heading 原门槛仍失败，则不称修复；保留失败，禁止现场调 b、叠 center 或换评分。只有原全部门槛通过才推进更广转向/停车组合门禁，障碍/跳跃/提速仍后置。
