# B22 48：优化后的研究方案（2026-10-20）

本方案取代此前"继续加奖励臂"的思路。依据：[开源对照与诊断](b22_open_source_review_20261020.md)与 [47 seed 复制结果](b22_seed47_results_20261020.md)。

## 一、诊断结论（决定方案的三条事实）

1. **瓶颈是更新次数/样本量，不是奖励形状。** 我们 32 次 PPO 更新、单环境、32768 samples；官方 D1 是 4096 环境 × 6500–20000 迭代（6×10⁸–2×10⁹ samples）。
2. **我们的跟踪核函数已经比开源更尖**（小误差二次系数 32 vs 4–8），所以"exp 在小误差处太平"的假设不成立，42–46 的奖励形状方向缺少理论基础。
3. **残差动作远未用满**（量程 4–9%、零饱和），所以"给粗糙地形更大控制权限"也缺少证据。

推论：在现有 32k 步微调范式下，**任何 1–2 点的臂间差异都不可测**；seed 摆动最大 7.4 点。继续加臂只会产生更多无法判读的数字。

## 二、P0：先修评测方法（不占算力）

- **每个条件至少 3 个 seed**；报均值、极差与 95% 区间（[rliable](https://arxiv.org/abs/2108.13264) 的 IQM/分层 bootstrap 思路）。n=2 时只允许用"分离规则"，不做区间推断。
- **主结果口径固定**：镜像合池比为主，raw 为次，两者都报；禁止事后挑选。
- **预先写判定**：比较前把规则写进设计文档，跑完只执行规则。
- **新评测集**：
  - 开发集 D1：6 任务 × 2 个新 seed（12 例），可重复使用，仅用于开发期比较。
  - 封存集 S1：6 任务 × 3 个新 seed（18 例），**只在最终候选上使用一次**。
  - 两个集合的 zero 基线各跑一次（zero 与策略无关）。
- 实现提示：冻结的 `recipes22.CASE_SPECS`/`make_schedule` 只接受已登记 id 与固定 seed，新集合必须在私有副本中注入并加测试；不得改冻结文件。

## 三、P1：用一次低成本实验回答"预算是不是杠杆"

**约束**：冻结课程只封存 80 个源回合（每回合 1000 拍），现有规格下训练预算上限 ≈ **80000 controls**。2× 预算（65536 controls = 66 回合）在封存范围内；4× 超出，需要新课程规格。

**实验**（β=0，奖励不变，只改预算）：
- 1×（32768）已有 2 个 seed：0.9324 / 0.8586（镜像）。
- 2×（65536）× 2 个新 seed（201031、201041）。
- 成本：每臂训练+读回约 35 分钟、导出 3 分钟、评测 14 分钟 → 两臂约 **1.8 小时**。
- 实现：`spec.training.controls_per_arm_per_stage` 改为 65536；`learning21.load_warm_start20` 里有 `BudgetSpec(32768,1024,256,4)` 的硬校验，需与 47 的 `STAGE_SEEDS` 同样用内存副本替换并加测试；其余冻结文件不动。

**预注册判定**：
- 若 2× 的镜像均值比 1× 改善 > 0.01，且极差不变差 → **预算确认是杠杆**，此后所有比较固定用 2×、n≥3。
- 若改善 ≤ 0.01 或极差变大 → **本地微调范式已到极限**；停止本地奖励调参，转入"结果收束 + 论文写作"，并把预算限制写成明确局限。

## 四、P2：只有在 P1 确认杠杆后才继续

按以下顺序，每次只改一个变量，n≥3：
1. 奖励项（若仍要做）在 2× 预算下重测，而不是在 1× 下继续加臂。
2. 跟踪项门控（开源做法：乘以直立系数）作为单变量候选。
3. 域随机化（摩擦/质量/延迟）——当前训练未启用，属于泛化问题，和跟踪误差分开评估。

**不再做**：
- 控制权限/动作空间改动（证据反对：零饱和、4–9% 量程）。
- 端到端重训（需要 10⁸–10⁹ samples；本机不可行）。
- 在 1× 预算下新增任何奖励臂。

## 五、需要你决定的三件事

1. **是否接受多 seed 成本**：任何未来结论都需要 n≥3，单次训练的结果只能作为观察。
2. **是否新开课程规格**：只有它能把预算推到 80000 controls 以上（4×、8×）；这是研究设计层面的决定，不是调参。
3. **是否关闭奖励形状方向**：我建议关闭——核函数已比开源更尖，且 47 已给出零结果。

## 六、诚实的边界

本机无 GPU、任务组 3 GiB，无法复现开源的并行训练规模。即使 P1 成功，2× 预算仍只有官方 D1 的约 1/10000。因此本仓库的定位是**小样本残差微调研究**，其结论不能写成"达到开源四足 RL 水平"。
