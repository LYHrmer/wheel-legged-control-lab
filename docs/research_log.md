## A/D 横移线：速度上界是结构问题，不是学习问题

这条线的结论被后续轮次多次修正，按时间读：

**C30–C31（2026-10-01）** [固定参考与 RL 前置验证](ad_lateral_skill_20261001.md)：六场配对、约 8% 固定参考提速和安全取消记录。[侧移 RL 结果](ad_lateral_rl_20261001.md)：64 周期训练与十场评估，物理资格通过，**额外提速未达标**（额外收益仅 0.10%–0.41%），GUI 尚未接入。

**C32（2026-10-03）** [价值拟合诊断](ad_lateral_value_diagnostic_20261003.md)：冻结数据支持旧 value 数值欠拟合，**离线拟合不等于 RL 提速**。

**C33（2026-10-03）** [固定时序与耗时诊断](ad_lateral_timing_20261003.md)：八场独立通过，30 mm 仍需 9.37 s，**提速门未达标**。

**C34（2026-10-03）** [速度补偿结果](ad_lateral_tracking_20261003.md)：唯一左向 30 mm 案例从 9.37 s 降至 8.83 s，但**目标误差与保持率门失败**，已按合同停止；完整独立读回通过，没有合格提速或 RL 收益。[新主路线](main_plan_20261003_ad.md) 转向连续横向速度与接触相位调度，最低工程目标 0.02 m/s 尚待验证。

**C35（2026-10-04）** [两支撑横移固定可行性结果](ad_lateral_pair_feasibility_20261004.md)：在第一例被四轮支撑门禁终止，**无任何实测横移速度**；根因定位到两份冻结 clarification 互斥。

**C35 复审（2026-10-04）** [步态方案重审与运动优化](ad_lateral_gait_review_20261004.md)：三个独立约束各有免费修法；精确 Jacobian 显示冻结脚速只用到参考限幅 10.9%，换最小时间剖面后**推算**可在不放宽任何硬限幅下达到 **0.07317 m/s**（冻结基线 3.10 倍、发展目标 1.83 倍）。瓶颈转为 60 mm 落点帽。**零物理步、零模型构造 —— 这是推算值，未测得任何实际横移速度。**

**C36–C38（2026-10-08）** [物理验证](ad_lateral_c36_38_physical_result_20261008.md)：pre-unload 门禁修正被物理证实（支撑和余量 45%），**C35 的静力推断被否证**；真正阻塞是两返回轮翘板振荡；途中发现并修复 MuJoCo 3.12 的 `qM` 潜伏缺陷；独立审计首次完整闭环。零训练。

**RL 范围界定（2026-10-05）** [有界合同草案](ad_lateral_rl_contract_20261005.md)：提速是结构问题不是学习问题；摆动反作用无法靠策略整形降低（同相 bang-bang 已达下界）但可精确前馈；唯一 RL 裕量是接触准入等待，20% 贡献门能否过取决于尚未测量的实际等待。**草案，非执行许可。**

## 延迟与随机化：增加历史没有带来稳定改善

[九模型延迟对照](../results/d1_v3_delay_ablation/README.md)：20 ms 下单帧、四帧、四帧加随机化分别完成 **2/12、0/12、1/12**；30 ms 下**均为 0/12**。增加历史与随机化训练都没有带来稳定改善，全部模型及失败记录保留。

整包测量延迟加到 20 ms 后，融合状态下的轮腿零残差在开发道路四个案例全部失稳（2.05、1.20、0.91、4.41 s）。把轮速增益改成 `0.55 / 1.5 / 4` 后，8 s 平地转向探针的累计转角达到指令积分的 70.8% 和 70.7%，但完整开发环境的四个案例仍在 3.1 s 内失稳；**默认增益保持 `2.2 / 3.0 / 4.0`**。记录在[延迟诊断目录](../results/d1_v3_delay_diagnosis/)。

## 读这份日志时的注意事项

1. **推算值与实测值要分开。** C35 复审的 0.07317 m/s 是运动学推算，且其静力前提已被 C36–C38 否证；A/D 线至今**没有任何合格的实测横移速度**。
2. **工程资格门与 RL 贡献门是分开判的。** 七场景通过、课程收益通过都不等于 RL 超过基控。
3. **"真实台阶"指真实碰撞几何，不是实机。** 全仓库没有实机验证。
4. 失败记录、失稳时刻、未通过的门槛都原样保留，不因后续改进而删除。
