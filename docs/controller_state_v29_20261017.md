# continuous 留出日志的控制器状态诊断 v29

本轮给既有 continuous 传感器策略补充一个只读诊断入口：按阶段汇总已记录的 PI 积分、偏航误差、Fx/Fz 残差和饱和计数，所有比例保留分母。它没有运行模型、GUI、MuJoCo、训练或物理积分，也没有改写旧轨迹或评价门槛。

范围是 `sensor45_v1` 的最终 **18 个留出配对**，不是当前 B22 的 99D/16D actor。本轮检查的两个 B22 历史目录没有对应 CSV；其 gz JSONL 记录没有在这里解析。不能将本报告推广成 B22 状态诊断。

## 入口与身份

```bash
rtk proxy /usr/bin/python3 -S -B scripts/diagnose_controller_state_v29.py \
  --run results/d1_continuous_policy/sensor45_v1 \
  --audit results/d1_continuous_policy/analysis_sensor45_v1 \
  --output results/my_controller_state_v29.json
```

输出必须是新文件，且位于实验及审计输入目录之外。退出码 0 表示完成日志诊断，1 表示留出配对存在 `INCOMPARABLE`，2 表示输入、身份、时钟或输出错误。

入口直接复用 [v28](continuous_comparison_v28_20261016.md) 的实验清单—协议—审计—指标关联和预定配对矩阵；任一留出配对未完成、时长不同或缺失时，全部状态摘要留空，不只分析幸存案例。随后逐份流式读取所选 `protocol.json` 与 `telemetry.csv`，核验原实验清单内的 SHA。报告绑定五份小输入和48份新增读取输入的 SHA/字节数，另绑定 v28 helper 与本入口源码的 SHA。

CSV 还必须具备连续的 0.01 s 控制时钟、对应协议的阶段与阶段时钟，以及合法的完整终止标记。已有动作和残差力字段同时存在时，核对 `[11.25,20] N` 映射。不会重读 NPZ、模型、checkpoint 或整份源码归档，也不重新授予原始实验真实性或控制资格。

## 记录了什么，缺少什么

| 内容 | 现有 CSV 能支持的结论 |
|---|---|
| 阶段、阶段时钟、实际 yaw 命令/速度/误差 | 可按实际记录时钟分组；命令在阶段切换处有渐变，不能用阶段名称代替当前命令符号 |
| `yaw_integral_nm`、`yaw_differential_torque_nm` | 可汇总记录值；首个积分值已经过该控制拍 PI 更新，不是切入前的记忆快照 |
| Fx/Fz 动作、残差力、`torque_saturation_fraction` | 可区分动作裁剪端与记录的执行器力矩饱和 |
| `reference_x/y/yaw` | 是路线参考，不能当作 LQR 内部距离参考 |
| LQR 内部积分距离/距离参考、完整45D actor、基线纵向力/支撑力 | `NOT_RECORDED`；不推断、不补零、不从真值路径反算 |

旧分析器已经给出阶段质量/RMSE及整体配对，旧文档也提到反向时 PI 卸载的可能影响。本入口新增的是完整配对准入后的状态计数、实际分母和字段可用性清单。每阶段分为 `0 < stage_time <= 1s` 与其余控制拍；**首1s是本次描述窗口，不是预注册资格门**。空窗口、没有非零 yaw 命令的窗口返回 null 比例；字段缺失返回 `NOT_RECORDED`，不伪造数值0。

## 这批存档显示的现象

24 个唯一运行包含六个共享零基线与十八个策略运行，共 **114,000 行**。三个训练种子各对应六个留出条件，基线复用不增加独立样本数。

| 运行组 | 总控制拍 | 竖直动作触及裁剪端 | 记录的力矩饱和拍 | 右转首1s积分与实际非零yaw命令反号 |
|---|---:|---:|---:|---:|
| 零基线，六条件 | 28,500 | 0 / 28,500 | 0 / 28,500 | 402 / 594 |
| 训练种子19000，六条件 | 28,500 | 28,500 / 28,500 | 0 / 28,500 | 402 / 594 |
| 训练种子20000，六条件 | 28,500 | 28,500 / 28,500 | 0 / 28,500 | 402 / 594 |
| 训练种子21000，六条件 | 28,500 | 28,500 / 28,500 | 0 / 28,500 | 402 / 594 |

每组六个右转首1s窗口共有597个记录拍，其中594拍满足非零yaw命令条件；45/50 s 时间缩放使部分阶段边界不落在完整控制拍上，因此这里直接报告实际分母。策略各阶段窗口的竖直残差均值均为 **+20 N**，零基线为0。这是确定性留出推理日志，与旧报告的训练 Gaussian 采样裁剪比例不同。

右转首个记录点的 PI 积分范围，基线为 `0.5512–0.5683 N·m`，三个策略组分别为 `0.5789–0.6084`、`0.5798–0.6113`、`0.5762–0.6007 N·m`。但反号拍数在基线也同样存在，不能称作 PPO 独有故障。

右转首1s的离地高度 RMSE 相对同条件基线，三个训练种子的六条件等权平均差依次为 **+3.972、+3.983、+3.917 mm**。这是窗口内 RMSE 差的描述，不是新增全任务通过判定、置信区间或跨种子总体改善。

这些现象支持两个下一步候选，尚不支持因果结论：

1. 将 PI 记忆及同拍 actor 输入显式记录在新的实验版本中，检验反向过渡时是否存在需要新增观测的状态歧义。**未在 actor 中显式携带不等于不能由其他观测估计**；当前 CSV 不足以证明 state alias，也不能拿事后真值 yaw 误差代入同拍 PI 的传感误差公式。
2. 核对当前 continuous 策略为何在所有阶段持续处于竖直动作裁剪端，并把高度误差按阶段对照。已有 Fx/Fz 参数化消融包含负结果，本轮没有证明去掉 Fz、减小其尺度或修改 PI 就会改善；这需要新合同下的单变量检验。

## 验证与证据

[机器报告](../reports/controller_state_v29_20261017.json)保留逐案例、逐窗口数值、字段可用性、输入身份和按训练种子区分的紧凑索引。

**21 项小合成测试通过，Ruff通过。** 合成反例使整回合及右转窗口积分均值都为0，但右转仍有2/4拍积分与命令反号；新摘要能保留这一现象。另覆盖缺积分字段、零分母、首1s边界、缺首/中拍/仅终拍、错误阶段、失败终止、NaN、力映射错误、清单篡改、配对缺失不做幸存者分析、标准库CLI及拒绝覆盖。测试还禁止通过 `read_bytes()` 整体读入原始CSV/NPZ/权重。
