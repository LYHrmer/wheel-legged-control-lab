# 54–55：D1 梯度精度与物理参考诊断

2026-11-01。实验在独立的 D1 仓库执行；本仓新增物理步、训练更新均为零。两仓原演示、模型与资格结果分别保留，未重跑 48、未修改冻结源或重绑 runtime v27。

54 将独立梯度工具的完整计算链提升为 float64，原 ε=.001 与容差不变：**54/54** 模型自检通过，五档步长合计 **270/270** 通过，原 ε 下最大自动微分/中心差分差为 **3.660743e−7**。自由模型对原九点的方向匹配仍为 **9/9、8/9、8/9**，因此算术精度修复并未消除所有模型方向偏差。

55 验证“用真实基线前向、学习模型局部导数反向”的离线估计器。三条新完整基线、54 条扰动分支全部完成，但两个点的真实差分参考不稳定，两个方法均只有每模型 **7/9** 个有效匹配，未达到额外设置的三模型各九点全通过门；完整控制对照没有启动。这种估计器依赖已观测的基线轨迹，不能当作独立预测模型。

55B/55C 独立诊断保留原失败结论。对全部九点预先固定四档小 ε，要求中心差分与单侧差分同时稳定；55C **9/9** 点通过局部规则，**90/90** 分支完整，首拍实际四轮扰动最小仍为 **33 个 float32 ULP**。该结果限定于所检验的小邻域，未事后重判 55。

55 含 admission、正式验证及两轮独立诊断，共 **14264 policy / 142640 native / 71320 PD**，模型与策略更新均为零，无新增控制性能提升结论。下一步需单独检验自由闭环模型的响应方向，不能用状态拟合误差代替梯度验证。
