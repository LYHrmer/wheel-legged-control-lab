# 2026-09-30 主路线：证明 RL 收益，交付最新策略驾驶入口

目标仍是 **稳定直行 → 可靠越障 → 提高速度**，以强化学习为核心，形成可以运行、比较和复核的运控作品。本方案接替 [09-29 历史方案](main_plan_20260929.md)；历史方案和已经结束的实验保留原样。本轮只更新方案和导航，以下候选预算均未预占，未启动新的 RL、机器人或 GUI 实验。

## 2. 下一项 RL 实验：同基控上的课程覆盖对照

研究问题是：**在 C18 基控上，从同一旧策略继续学习，明确的联合命令覆盖能否改善 yaw/bumps 跟踪，同时保持已有能力？**

C15 增量训练每臂 16,384 控制。课程前八个 episode 是平地 warmup，其中包含低／中速转向；后续八槽循环仅一个 flat yaw 槽、一个 bumps 槽。yaw 采样为 `vx∈[0.6,1.2)`、幅值 `∈[0.15,0.3)`，正式 `1.2×0.3` 联合端点未被这段课程直接采样；训练与正式转向窗口也不同。这个源码事实支持课程比较，尚未证明退化原因，也不能外推为父 65k 训练没有该覆盖。配方见 [recipes15.py](../results/d1_main_route_execution_20260930_15_16/stage15/recipes15.py)。

| 比较项 | A：原课程再适配 | B：命令覆盖课程 |
|---|---|---|
| 起点 | 同一 grouped final、同一 Adam 状态 | 相同 |
| 控制与学习接口 | C18；相同 99D/16D、奖励、网络、学习率、分组裁剪与保护 | 相同 |
| 共同优化规则 | 两臂采用相同、合同前冻结的 `target_kl` 护栏 | 相同 |
| 主要差异 | 保留原课程命令分布 | 显式补联合端点、左右对称及进入／反向／退出覆盖 |
| 地形与 warmup | 同一地形槽位、比例与 warmup 规则 | 保持；不同时增加地形权重或取消 warmup |
| 预算与随机流 | 相同环境控制上限、优化机会和配对随机流规则 | 相同；命令差异单独记录 |

B 的具体格点、过渡窗口与 bumps 速度覆盖在执行合同前一次冻结。统计 **实际 servo 命令 × 地形／接触 × 残差有效窗口**，并记录轮／腿动作与真实控制输出；只数 raw 命令或总 tick 不算有效覆盖。若需要同时改变多个课程规则，合同应明确检验整个课程包，结论不得单独归因于某个格点。

A 相对旧策略观察在新基控上的继续学习，B 相对 A 才回答覆盖课程的作用。保留 **zero、旧 grouped、A final、B final** 四个评估对象。旧 checkpoint 对 C18 的适配、课程效果与 RL 超过 zero 的结论分别报告。

C15 grouped 首 rollout KL 约 0.632，支持两臂共同设置更新护栏，但不直接决定新阈值。合同须先确定阈值、SB3 实际触发语义和阶段停止门；必要纯测试核计数与提前停止路径。首更新观测计入训练预算。KL 护栏不撤回已更新参数，也不天然结束整次 learn；实际 optimizer 次数可能不同，按实数报告，不能补更新凑齐。A 是共同新优化规则下的原课程再适配，不能称为 C15 忠实复现。

### 有限训练与一次续段

| 待执行合同候选 | 训练 controls 上限 | 条件 |
|---|---:|---|
| 首段：A／B 各 32,768 | 65,536 | 先冻结来源、课程、优化护栏、样本门、评估与封存预算 |
| 可选续段：A／B 各再 32,768 | 65,536 | 仅在预注册开发继续门全部成立时执行一次 |
| 总训练上限 | **131,072** | 非本轮执行额度；不因失败或样本不足补步 |

32,768 步名义上可容纳八个 warmup 与三个八槽周期；提前终止、servo 过渡或接触不足可能使实际覆盖达不到要求，因此不承诺这些步数一定足够。低速 floor、开发／最终评估、compiler 调用、加载／probe、原生子步和封存 wall time **另外列账**，不能藏入训练上限。

续段决策只看事前固定的开发验证集和原七能力回归集，最终保留集保持封存。建议执行合同采用以下继续门，并在首段开始前冻结：

- 实际更新、来源／计步、关键命令覆盖与接触证据有效，没有记录故障或更新失稳。
- 新开发 yaw/bumps 集合中，B/A 合并 drive SSE≤0.90、B/旧策略≤0.95；每类 B/A≤1.02，保留全部失败。
- 原七任务中的 B 能力无回退，速度、真实几何与停车仍按原门；B/zero 成本比≤1.20，B/A≤1.10。
- 改善同时报告 drive／保持／过渡窗口，没有靠窗口移动、只延长加速段或成本增加制造结论。

这些是设计门而非已获得的效果。合同还须固定任务权重、SSE／成本池与失败计分；不得只合并有利或存活场次，合法早停计任务失败，不能凭前缀误差较小获得继续资格。有效比较未达继续门时，结论是这次数据不支持扩训；来源、覆盖或更新无效时，比较无效或证据不足，假设仍未定。两者都结束本次、不补步、不自动进行第三段训练。若续段成立，延续课程 episode offset、Adam 和预定随机流，避免再次从八轮 warmup 起步；跨进程 reset 与下一 episode 规则须事前声明。

## 3. 评估设计：回归、开发和最终保留集

1. **原七脚本是能力回归集。** 原六对贡献门不改：记录／安全先决、能力无回退及 policy/zero 成本≤1.20 为共同条件；A 分支要求至少一项真实任务失败转成功，B 分支要求至少四项共同通过、合并 SSE≤0.85 且至少四对单项≤1.02。镜像独列，不改分母。旧结果与门原样保留。
2. **开发验证集参与续段决策。** 使用事先固定的新转向时序、持续时间、速度—yaw 组合和 bumps 进入相位；先锁窗口，再运行。与原七能力回归集共同判断继续门，最终保留集不参与。
3. **最终保留集一次判定。** 在任何训练之前封存不同的实际命令／进入条件，最终策略取预定预算末端，不按保留成绩挑 checkpoint。未通过时保留原结果；调整训练需要新的问题和合同。

本次课程对照先改变少量可解释条件。保存实际 qpos/qvel、几何、servo、随机流和接触身份，确认条件确实进入物理／观测。摩擦、载荷、传感器噪声与时延另设后续挑战集，首轮不同时堆叠。

相同随机流不保证两个已经不同的策略拥有相同后续轨迹；只能保证预先约定的外部条件与初态配对。不同课程也不能声称首 rollout 逐位相同。统计单位是 episode 与独立训练实现，轨迹内数千 tick 不能充当数千个独立样本。一对训练实现只提供开发证据，可靠性和方法层结论需要另立多实现计划。

避免重复已有物理批次：原七场 zero／旧策略成绩只有在新合同事先允许跨会话复用，并核对相同控制器、编译几何、命令与评分规则、五个初态数组及完整控制器初态（PI、z 等）一致时才能作为锚点；不符则停止该配对结论。新命令场景的锚点须真实执行，不从旧表外推。最终评估预算由确切的 `actor×case×horizon` 表求和并事前冻结。

## 4. 与 RL 对照并行：交付当前策略的可用 GUI

先完成 **C18 + 当前 grouped 的版本化运行入口**，不等 RL 额外收益达标后才做演示。现有 `d1-rl` 使用旧 05/06 策略；C13 仅验证旧 99D/16D final 的 0.6 m/s、600 步固定 GUI 脚本。这两者均不等于当前 C18 自由驾驶，具体版本见 [当前状态与入口](current_status_20260930.md)。

新入口需要显式的运行 bundle 和模型卡：固定源／引擎／checkpoint 身份、99D/16D 编码、控制器与 probe；解决历史绝对路径和依赖布局，输入输出目录自动独占创建。采用新模块或版本化副本，保留冻结源码；不同观测或权重不兼容时清楚拒绝。完成验收后再发布短启动命令。

GUI 分两次交付：

- **脚本演示**：实际加载当前 final，选择已资格任务和 zero／RL 对照；真实控制 owner 独占物理与策略，渲染只读快照。新 GUI 条件下核对 headless／GUI 同输入数值、来源与计步，并展示速度、目标、策略状态及保存结果。
- **限定按键驾驶**：另验 W 前进、Q/E 双向转向、释放／Space/X 停止、失焦／过期输入、R 仿真复位和退出保存。倒车、任意速度—转向组合与新增地形须有自己的输入序列资格。1.6 m/s 直行通过不开放 1.6 m/s 同时转向；A/D 与 Space 跳跃待技能资格后接入，停止键与跳跃键的映射届时明确区分。

复用 C13 的软件渲染基础性能门：RTF≥0.8、FPS≥8、poll／快照年龄 p95≤250 ms；用户桌面另外量测启动时间、实际按键到 servo 的延迟、失焦停止、帧率和短时人工试驾。较流畅的体验目标可设 RTF≥1、FPS≥30，但不能把新增目标冒写成已验证门。Xvfb 脚本成绩不等于用户 GPU 或人工体验通过。

能力、RL 收益和 GUI 体验分别验收。策略即使尚未超过 zero，也可以作为明确标注的真实 RL 演示；只有具体 actor×terrain×命令组合与输入保护通过，才开放对应 GUI 能力。`qualified_for_default_GUI` 目前仍为 false。

## 5. 可靠越障：真实 15 mm 闸与新技能

**真实 15 mm 单台阶紧跟上述阶段，不等待无限鲁棒化。** 为 C18 + 当前策略新立低速 zero／learned 同初态合同，先取 0.20 m/s 作保守候选，C18 须独立验证；新合同至多 **2,400 controls／12,000 normal native**，compiler／静态几何调用另外声明。运行前冻结具体 pair／horizon、接触门、整轮清除与停车窗口，并确认所选出生位置和时长能够容纳完整任务。

先核真实立面／台面几何、正轮载荷与接触，再核四个整轮清除、姿态、非轮接触、真实速度和停止。旧 06 策略、bumps 和 ramp 都不替代该闸。通过后只开放对应低速台阶；0.25 m/s、连续地形、高速越阶或新训练策略需要各自资格。失败时仅选择一个有证据的接触／腿姿态／动作权限分支，不自动追加训练。

A/D 与 Space 后排、分别学习：横移先检查腿外展／支撑切换权限和真实 vy 可行性，再验纵漂、yaw、姿态与非轮接触；跳跃先核准备、真实离地、落地冲击与恢复。旧两次平地跳跃失败应先解释，禁止第三次同构盲训。R 始终是仿真复位，物理自救尚未实现。
