# B22 关门时跳过无效推理：独立配对32

这是新版本的有界推理优化，不改变旧 v27、C26、收尾30或矩阵31的源码、产物和资格。**当前只有代码与合成检查；真实整段行为等价尚未验证。**

固定同一 B22 最终权重 `7bd58b5d…d76691`、原 C18 控制器、99D/16D接口、script/flat_1p6、seed181202。新 worker32 从稳定 worker31 (`49feaecf…5d7c0`) 明确派生，只改变32准入、推理选择与推理日志位置；整模块 AST 必须等于登记的精确变换，其余控制、观测、命令、奖励、归档与清理流程保持相同。

两个串行新会话使用同一 worker32 源码：`baseline` 每拍执行原 SB3 确定性推理；`gated` 在原控制器对**当前 `env.decision.world_command`** 返回 `False` 时提供 float32 零动作而不调用模型。门依据原 raw forward/lateral/yaw/jump 请求与显式探针，不能用平滑后的 servo 速度、机器人运动量或 GUI 输入决策替代。关门仍执行完整控制拍，更新 wheel PI、z、停车 latch、上一拍实际有效动作和观测，完成原五个 native 区间。

固定 B22 的严格加载器必须先核权重、MLP结构与32行 byte-exact 探针，保留其一次批量 `predict` 调用。这里不支持复用其他权重、循环网络或有推理副作用的 actor。跳过的神经策略输出记录为 `null / NOT_OBSERVED`；它与实际送给控制循环的零动作分开，不伪造原本没有计算的策略值。

| 本轮最大值 | 每会话 | 两会话合计 |
|---|---:|---:|
| 控制拍 | 1600 | 3200 |
| 正常 native | 8000 | 16000 |
| 原编译探针 native | 2 | 4 |
| 模型加载 / torch_load | 1 / 3 | 2 / 6 |
| predict 上限（包括加载探针） | 1601 | 3202 |

两会话加编译探针总上限为16004 native，属于新32预算，不复用31或30余额。每会话沿用原180/235/240秒门，外层进程300秒；只读比较180秒，总900秒。启动需6GiB有效RAM，运行保留3GiB，host/cgroup-v2祖先余量取最小值，swap不算RAM。磁盘启动保留1GiB，运行保留512MiB。独占 `results/b22_inference32_*`，失败不重试、不续跑。

默认入口只显示计划，不加载模型或执行物理：

```bash
rtk proxy python3 -B scripts/run_b22_inference32.py --output results/b22_inference32_YYYYMMDD_01
```

所有新源码提交并具备可复核来源后，资源达标才可用同一入口的显式 `--execute` 执行。当前按用户选择等待外部 IsaacLab 任务结束，不抢占该任务或关闭其他人的进程。

独立 reader 从新 release、两份 session/worker 回执、事务SHA、完整1601状态端点、逐拍控制与全部8000 native行复核。沿用冻结 C26 的纯控制/接触/执行器检查；新模型调用核验独立处理 gate 语义。两组初态、全部 qpos/qvel/ctrl/warmstart/99D观测、有效动作、扭矩、PI、z、stop latch、奖励、命令、终止与逐native状态/接触必须严格相等；不使用 `np.allclose` 接受轨迹漂移，不只比较终点或均值。

原固定 raw 门预计720拍开、880拍关。成功时只可声称少880次控制推理：baseline 为1600+1次，gated 为720+1次。它不代表总CPU或墙钟减少55%，不新增RL贡献、泛化、ROS或实机资格。原始策略日志在关门时不同是预期变化；其他控制与物理差异均使比较失败。只有新真实配对回执通过后，才可标记本固定范围内行为等价。
