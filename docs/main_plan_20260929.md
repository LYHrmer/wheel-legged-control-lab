## 优先级一：确认能力边界，先解释 RL 跟踪退化

不重训 65,536 步。独立读回已核验完整训练、真实更新、final 字节、九场原生链与四对逐位初态，没有加载策略或重放物理。四对任务都通过，但原评分驱动窗口内的策略跟踪 SSE 和归一化力矩平方成本均高于 zero：

| 已完整任务对 | 策略 SSE 相对 zero | 力矩平方成本 policy/zero |
|---|---:|---:|
| flat 0.6 | +53.054% | 1.0593 |
| flat 1.6 | +132.413% | 1.1326 |
| flat 1.2 + yaw | +9.494% | 1.0808 |
| bumps 0.4 | +15.578% | 1.0429 |

这是四对已完成任务的描述性比较，不是六对总体贡献评分；力矩平方是成本代理，不是能耗。四对都超过原 branch B 的逐对 SSE 上限 1.02，剩余两对即使满足，也凑不齐要求的四对，因此**本模型的 branch B 跟踪改进路径已被现有结果否定**。branch A 的任务失败转成功路径仍未定：rough zero 已通过，不能在该任务形成转换；尚未开始的 ramp pair 仍可能形成转换，但还必须满足其余安全、无能力退化和总体成本门。不能把四对跟踪退化写成整个 RL 贡献门已完成或必然失败。

下一科学优先项是利用保存数据分解一致的正向速度偏差：按加速/保持窗口分开速度与 yaw SSE，再检验共同轮速残差、腿姿态残差及目标/力矩限制与误差的时序关系。随后核奖励和 return 尺度、终止/bootstrap 与价值拟合；先区分已观察到的偏差和可能机制，不直接把负 EV 或高 KL 定为原因。已有四任务能力可作为后续 GUI 验证的候选范围，当前没有新的 GUI 执行资格；也不因能力通过而把该模型宣称为优于 zero 的默认策略。

仅当缺失任务的结果能决定一个具体后续选择（例如某个地形是否值得保留此模型作候选）时，才提出相应补评估。**三场全部补齐的上限候选是 rough policy 1,600 + ramp zero 1,800 + ramp policy 1,800 = 5,200 控制 / 26,000 normal native，另列冷构造上限 2；这不是默认下一预算。** 一个新进程；训练、保存新模型均为零；同一 final 严格加载一次、保存 probe 一批，三场全选时正式 policy 预测最多 3,400 次，zero 不调用策略。只使用当前模型 `6cf2db80be7b990efc8be40eff307e58351eae839970b0c78ce5c9b5193f8e70`，任务、seed、评分和数值控制保持原样。合同须先写明待解决问题、所选场次和结果对应的决策；**本轮不执行，也不预占这 5,200 控制。**

若选择 rough policy，须从原 seed 初态完整重做，不接半写尾块、不补跑某几个 tick、不重复九场完整评估。与旧 rough zero 的跨会话配对须事前声明，并逐位核 qpos/qvel/ctrl/warmstart/99D 观测及编译几何/源身份；不符则停止配对资格。新旧 C/Python 帐分别闭合，按实际报告“九场原运行 + 所选恢复场次”，不冒称原进程完成十二场。合法任务失败保存后继续合同内剩余场，不重试挑结果。

## 优先级二：先修中断与耗时预算，再谈更多实验

此次训练已耗 1,348.38 s。SIGTERM 打断 gzip 后，finally 同名 `xb` 写入触发 `FileExistsError`，遮蔽超时；不能解释成物理失稳。新版本应采用临时块完成 close/fsync 后原子提交、manifest 最后登记；失败块标 partial，finally 不重复提交、不覆盖首异常。软停止只锁存请求，owner 在完整 tick/提交边界封存，硬 watchdog 独立兜底。

将训练、资格评估、GUI 分为独立可闭账阶段。根据已完成场次的真实 wall time，为剩余全量接触记录、加载和闭账留余量，不用裸积分速度估算。模型调用改为明确入口的轻量计数，保留 C 硬预算；全局 `sys.setprofile` 是可能开销，尚无对照，不能编造加速倍数。每阶段一次集中接口审阅，必要测试首过即止；不反复跑旧批次。详见[记录边界说明](rl16_engineering_followup_20260929.md)。

## 优先级三：让 RL 收益成为可证伪的问题

[保存的诊断](../results/d1_rl16_progress_20260929/evidence/publication_20260929/learning_diagnostics_01.json)：有效残差窗口 53,986/65,536，门控零比例降至 17.62%（旧长课程 68.9%）；策略边界裁剪为零。approx KL 中位数 0.03456、clip fraction 0.3066，critic EV 中位数 −0.00174、末值 −0.00330，末 value loss 3243.996，std 约 0.136。这是价值拟合和更新幅度的诊断线索，**不是因果结论**；无策略裁剪也不代表目标限速/力矩保护没有抹掉动作。

先完成上述正向偏差分解，再分 terrain 和有效窗口核奖励/return 尺度、动作各维与实际关节/轮响应、目标和力矩限幅、终止/bootstrap。不能仅因平均速度偏高就手工减残差、加惩罚或重训；保存轨迹上的相关性不等于动作的反事实效果。未保存的 value/gradient 指标明确缺失，不假造。若确需改训练，下一合同只检验一个主要假设：价值尺度诊断与 `target_kl` 分开，固定控制器/观测/动作，不同时改课程、奖励、学习率和网络。记录实际 actor/value 梯度和 optimizer 数；KL 提前停 epoch 后不能仍宣称固定更新次数。先用有限保存批次做无机器人拟合诊断，得到依据后再讨论不超过 32,768 控制的单因素学习候选。所有这些均未在本轮获执行预算。

| 完整评估结果 | 决策与停止门 |
|---|---|
| 记录无效 | 修证据链，暂停资格；不靠重训补缺口 |
| 能力合格且贡献门通过 | 开放该 actor×terrain 的 GUI 验证；单 seed 不称普遍可靠 |
| 能力合格但 zero 一样好/更好 | 可以展示真策略运行，明示基线能力；不冒称 RL 提速 |
| 策略使 zero 的通过任务失败 | 暂不设该能力为默认，先查残差作用和更新机制 |
| 地形任务失败 | 针对载荷/轨迹/姿态/动作定位，不放宽门槛或盲加训练 |

1.6 m/s 仍核真实 COM 速度、RMS、超过 1.5 的占比和制动门，不看轮速或指令冒充。任何利用当前 heldout 调参的下一模型需新独立 seed，旧结果转为开发证据。新策略对真实 15 mm 单台阶还需单独固定场景资格；bumps/rough/ramp 不替代它。

## 下一阶段并行项：限域 GUI 交付，随后再扩新技能

本轮不运行 GUI。下一阶段可与保存数据的 RL 机制诊断并行完成 GUI12 可运行入口；不必等待 rough/ramp 补齐或总体 RL 收益门通过。修好中断归档后，在单独有限合同下，以真实 final 进行已核验范围的 GUI 数值与性能验收：flat 0.6/1.6 直行、原 flat 1.2+yaw 命令脚本、bumps 0.4 直行。验收范围按 actor×terrain×命令组合锁定，不能从几个离散任务推成自由组合或整个速度区间；1.6 直行不授权 1.6 转弯，台阶、A/D、Space 暂不开放。

实现单物理/策略 owner + GL/UI 只读快照的解耦；最新帧可以丢旧帧，输入带时间戳、失焦/过期停止。相同脚本 headless/GUI 核数值一致，再测 RTF≥0.8、输入延迟、帧率和快照年龄；软件 Xvfb 结果不外推到用户 GPU。日常 HUD 只保留速度/转向目标与实测、策略状态、地形和按键，注明“RL 策略运行；尚无已证收益”，哈希放日志。能力、RL 收益与 GUI 体验分别报告；在实际 GUI 验收通过前，`qualified_for_default_GUI` 仍为 false。这样可交付限域可用演示，同时继续解决 RL 跟踪退化。

**A/D 侧移**需要腿外展/支撑切换、真实 `vy` 任务和接触/相位观测；固定轮方向不能靠四轮速度伪装全向运动。先有限动作权限检查，再低速平地技能学习，以横移、纵漂、yaw、姿态、非轮接触比较 zero/learned；坡面另验。

**Space 跳跃**单列准备、起跳、腾空、落地恢复。先小高度可行性，再学习；必须记录真实离地、COM 高度、落地冲击/姿态和恢复，不瞬移或改显示。高速度与跳跃不同时开放。旧跳跃失败必须先解释，禁止没有新机制依据就进行第三次同构平地跳跃训练。两技能都走“必要纯接口检查 → 小预算物理可行性 → 一次有限学习 → 新持出评估”；失败先定位，不自动加预算，不承诺几十 k PPO 从零完成所有技能。
