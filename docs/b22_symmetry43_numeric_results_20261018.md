# B22 43 镜像策略数值准备结果

**新42 deficit8权重的低内存actor和左右镜像组合通过数值验证，尚未进行镜像候选的物理评测。** 此结果不改变42当前SSE比 .968869、RL贡献门未过的结论。

实际加载完整42模型一次，三次torch.load；对192个固定观测及其镜像执行384次SB3和384次NumPy推理，生成192个镜像均值。全部调用正常返回。SB3/NumPy逐元素最大差 **2.98023223877e-08**，镜像组合最大差 **2.98023223877e-08**，均低于1e-6；原保存32探针最大差 **6.70552253723e-08**。没有训练、环境构造或物理步数。

本次冻结源 `c2f1f65b3def761d6e60aede828a8f455941e8c1`，完整42模型SHA `44cbf9a4363ff42af78d8e54049e0dbade2bea74701e9a27073bcb9e656f3239`。六张量 `actor.npz` SHA `7320ec626cee2f6bf98ed4322840d4e4cacbc90ebd42726085b1385e5fc03c91`，旁路数值产物 `90c9f6df7f135b3414704a9a08d664c586ee91651815a067525fd409dcc82ee4`。独立只读回验核实SHA、384行精度与192行组合计算，未增加推理。具体记录见[机器摘要](../reports/b22_symmetry43_numeric_results_20261018.json)。
