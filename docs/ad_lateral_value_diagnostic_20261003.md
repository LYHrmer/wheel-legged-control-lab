# C32：冻结事件数据上的 value 拟合诊断

C32 只分析已归档的 C31 数据，没有采集新轨迹、训练 actor 或运行物理仿真。问题是：C31 最终 value 预测差，究竟因为原有 54 维观测不足以表示这些数据中的回报，还是因为有限训练没有把可表示的关系拟合出来？这份诊断支持后者的**数值欠拟合**判断，但不分辨具体训练原因，也不证明控制速度改善。

数据是 C31 训练档案中的 64 个完整周期、256 个真实 macro 事件。周期 0–31 的 128 行用于拟合，32–47 的 64 行用于验证，48–63 的 64 行用于报告测试结果；没有重排或重新采样。两个目标分别是原存档的 `value_target = old_value + GAE`，以及在每个完整周期内把已存 reward 以 γ=1 从后向前相加得到的实际回报。后者是这批轨迹的实现回报，不能据此称为变化中的采集策略下无偏的策略 value 标签。

固定比较包括八个“方向 × macro”训练均值 P、原 54 维观测加截距的最小范数普通最小二乘 L0、同特征且截距不受罚的岭回归 L1，以及八格截距加 48 个连续观测量的岭回归 H1。L1/H1 的岭系数均固定为 0.01。所有系数只用前 32 个周期估计，验证和测试行只用于报告。下表的 MSE 比值以同一目标、同一分割的 P 为分母；EV 是解释方差。

| 目标与方法 | 验证 EV | 验证 MSE / P | 测试 EV | 测试 MSE / P |
| --- | ---: | ---: | ---: | ---: |
| 已存 GAE，P | 0.9981 | 1.0000 | 0.9983 | 1.0000 |
| 已存 GAE，L0 | 0.9987 | 0.6959 | 0.9996 | 0.2371 |
| 实际回报，P | 0.9981 | 1.0000 | 0.9982 | 1.0000 |
| 实际回报，L0 | 0.9993 | 0.3514 | 0.9999 | 0.0823 |
| 已存 GAE，C31 最终 value | 0.0160 | 685.57 | 0.0159 | 754.13 |
| 实际回报，C31 最终 value | 0.0155 | 755.68 | 0.0153 | 831.92 |

八格均值 P 本身已有超过 0.998 的总体 EV：不同 macro 阶段的目标均值占据了大部分方差，因此单看总体 EV 很容易误判为模型学到了具体状态。更有区分力的是在这个基线上进一步减少误差。按预先固定的“验证和测试均须 EV≥0.8、MSE/P≤0.5”描述性标准，L0 对实际回报两段都达标；对已存 GAE，验证比值 0.6959 未达标，尽管测试比值为 0.2371。L1、H1 以及 P 均未在两个目标上达到这一组合标准。不能把其中一个目标的成功扩展成两个目标都已解决。

C31 已训练的最终 value 则远弱于这些只在冻结数据上拟合的描述性模型：已存 GAE 的测试 MSE 为 98.98，实际回报为 100.92，两者测试 EV 都约 0.015。它在全部 64 个周期上接受过 C31 训练，所以这里的“验证/测试”对这一个旧模型只是诊断分区，**不是未见数据的泛化验证**。L0 能在相同观测列上拟合实际回报，反驳了“原 54 维线性表达式根本容纳不了这批回报结构”的简单解释；但 L0 的设计矩阵 55 列中保留秩为 54，保留奇异方向的条件数约 432 万，系数不稳，不应直接拿来部署。固定的一次岭回归把低尺度方向压得过强、H1 接近阶段均值；这只能说明这一次固定设定的结果，不能宣称这些方法普遍无效。学习率、梯度裁剪、有限更新预算与移动的自举目标各占多少责任，本诊断没有做因果拆分。

真实 C31 数据只执行了一次离线诊断，执行收据记 0.215 秒、退出码 0、前后源码身份一致。实际计算账为 3 次双目标最小二乘调用（6 个目标拟合）、2 个目标的八格均值拟合、四种方法共 2,048 个标量预测，另用 NumPy 对冻结的 C31 `value.weight/bias` 计算 256 行旧 value 预测，总计 2,304 个标量预测；actor、B22、torch、优化器、物理与 native 积分调用均为 0。独立保存了逐行预测、系数、输入哈希、分割及方向和 macro 分解指标。

另有一项必须单独披露的合成检查范围偏差：最初的纯检查在审查纠正之前，实际消耗了 7 次**合成数据**双目标最小二乘、14 个合成目标拟合、4 个合成均值目标拟合和 4,096 个合成标量预测。原合同虽允许纯检查，却未单独为这些合成拟合编预算，并明确禁止额外拟合。该事实未被改写或并入上面的真实数据执行账；那时 C31 保存数据拟合、物理和模型调用均为 0，之后的唯一真实数据诊断仍严格使用原定预算，也没有追加拟合。

这些数字只支持离线诊断结论。C31 先前的 RL 速度门未通过；改进 critic 的离线拟合并不自动带来更快且通过原物理安全门的侧移。后续若研究固定时序或再次训练 RL，必须另立有限合同，并对同一控制权限下的强固定基线与真正未用于训练的条件分别评估。
