# 只用位置编码器做单轮动力学辨识

这次实验给[执行器辨识台架](actuator_identification.md)增加一个输入限制：拟合器只能拿到已知请求力矩和位置序列。它要从整段运动中估计附加惯量、阻尼、平滑摩擦和整数步延迟，再把参数交给[单轮速度控制器](wheel_control_lab.md)做前馈对照。

本页记录固定协议及[实际运行结果](#本轮结果)。全部数据来自 MuJoCo 单轴合成对象，不代表 D1 的真实电机参数，也不包含整机或真机验证。本轮没有训练新的 RL 策略。

## 从 PACE 借用了什么

PACE 用固定机身、无接触的关节激励辨识动力学。原方法记录位置目标和编码器轨迹，在仿真中用相同位置目标驱动关节 PD，以整段位置误差拟合参数。PD 增益与力矩限幅是已知量；轨迹误差不需要实测输出力矩或独立速度标签。低层 PD 自身仍涉及速度反馈。[论文 §2.1–2.2](https://arxiv.org/html/2509.06342v2#S2.SS2)

本项目保留“回放命令，比较位置轨迹”的做法，但直接输入已知关节侧力矩，台架内部没有位置 PD。这个改动适合先检查数据时序和拟合接口，却省去了位置驱动器的建模问题。

| 比较项 | PACE 官方方法 | 本次单轮实验 |
|---|---|---|
| 激励输入 | 关节位置目标，经已知 PD 产生力矩 | 已知尺度的请求力矩，单位 N·m |
| 拟合观测 | 关节位置轨迹 | 单轴连续位置，单位 rad |
| 搜索参数 | 关节惯量、阻尼、摩擦、位置偏置及全局延迟 | 附加惯量、阻尼、平滑摩擦及整数步延迟；不拟合偏置 |
| 优化与仿真 | CMA-ES，Isaac Lab | 枚举延迟，SciPy `least_squares`，CPU MuJoCo |
| 本页能检验的范围 | 原论文另有整机与硬件实验 | 合成单轴预测与 PI 前馈对照 |

官方代码与运行方式见 [leggedrobotics/pace-sim2real](https://github.com/leggedrobotics/pace-sim2real)。这里的优化器和输入接口均有改动，不能称为完整 PACE 复现。官方也要求在未参与拟合的运动上验证；本次按整段激励划分数据，没有随机打散时间点。[PACE 验证建议](https://pace.filipbjelonic.com/tutorials/best_practice/#3-avoid-overfitting-to-a-single-trajectory)

## 位置日志的约定

新的 `EncoderLog` 与旧的 `ActuatorLog` 分开使用。旧接口接收位置 `q` 和独立合成速度 `v`；新接口没有速度字段。

| 日志内容 | 约定 |
|---|---|
| `config` | 已知台架类型、物理步长和力矩限制 |
| `commands` | T 个请求力矩，单位 N·m |
| `positions` | T+1 个采样位置，单位 rad；第一个是命令执行前的位置 |
| `known_initial_rest` | 调用时必须显式传 `True`，表示初始速度已知为零，且历史命令为零 |
| `name`、`split` | 激励名称与数据用途；只有 `calibration` 可进入拟合 |

第 k 拍的含义是：

```text
q[k] ── 请求力矩 u[k] → 限幅 → d 步延迟 → 一次物理积分 ── q[k+1]
```

`d=0` 在这一拍使用 `u[k]`，`d=1` 使用上一拍命令。回放开始时延迟队列清零；`d=2` 就先执行两拍零力矩。步长为 0.002 s 时，两步延迟是 4 ms，不能当成整机 RL 实验中的两个策略步。

必须保留最后的 `q[T]`，否则最后一个命令没有对应的运动结果。角度按连续转动记录，不折回 `[-π, π]`。把一圈末尾折回零会引入约 `2π` 的假跳变。

`known_initial_rest=True` 是采集前提，不是由前两个带噪位置估出来的结论。如果采集时轮子仍在转，不能仅把这个字段设为真来通过校验；应重新采集满足初始条件的轨迹，或另行设计估计初始速度的方法。

回放只用 `q[0]` 初始化位置，速度设为零。此后每一步都由候选模型自己积分，不再把实测位置写回仿真。模拟器内部当然有速度状态，但它来自模型计算，不是额外的观测输入。拟合器也不接收生成数据的隐藏对象或实际施加力矩。

## 拟合的量与不能分开的量

单轮台架没有重力回复力矩，模型为：

$$
(J_L+I_a)\ddot q+b\dot q+c\tanh(\dot q/v_\epsilon)
=\operatorname{clip}(u_{k-d},-2,2).
$$

| 符号 | 含义 | 单位 |
|---|---|---|
| `J_L` | 已知轮负载惯量，0.00189225 | kg·m² |
| `I_a` | 待拟合附加惯量 | kg·m² |
| `b` | 黏性阻尼 | N·m·s/rad |
| `c` | 平滑摩擦幅值 | N·m |
| `v_ε` | 固定平滑速度，0.05 | rad/s |
| `d` | 请求力矩延迟 | 物理步 |

台架用质量 0.5 kg、半径 0.087 m 的均匀轮体，`J_L=mr²/2`。轨迹直接约束的是总惯量 `J_total=J_L+I_a`。只有把 `J_L` 当作已知量，才能从总惯量中减出 `I_a`；换一个未知负载，不能指望同一条轨迹同时分出这两部分。

力矩尺度也必须已知。在未触发限幅的数据里，若又把未知增益 `g` 放进右端 `g·u`，则同时按比例缩放 `J_total、b、c、g` 可以保持相同运动。单靠这组位置轨迹不能确定各自的绝对尺度。本次不拟合未知力矩增益；硬件上的电流指令也不能未经换算就当 N·m 输入。

在接近零速的区域，`tanh(v/v_ε)≈v/v_ε`，两项阻力近似为 `(b+c/v_ε)v`。只激励这个小范围时，阻尼和摩擦会相互补偿，拟合曲线接近不代表两个参数分别可信。正反向和不同速度范围的激励能帮助区分它们，但局部 Jacobian 满秩仍不能证明全局唯一。

轮轴在本模型中没有依赖绝对位置的回复力矩。对位置整体加一个常数不会改变运动，`q[0]` 已吸收日志原点。这里不再加入编码器零点偏置作为自由参数。平滑摩擦也没有静止粘滞区，`c` 不能解释成静摩擦启动阈值。

## 两种拟合怎样比较

每个整数延迟候选都重新拟合连续参数。两种方法共用参数范围，连续变量缩放到 `[0,1]` 后调用有界 `least_squares`。

| 参数 | 下界 | 上界 |
|---|---:|---:|
| `I_a`，kg·m² | 0.002 | 0.060 |
| `b`，N·m·s/rad | 0.001 | 0.350 |
| `c`，N·m | 0 | 0.200 |
| `d`，物理步 | 0 | 4，逐个枚举 |

令 `N` 为校准命令总数，位置残差使用固定尺度 `s_q=0.05 rad`。新方法的目标是：

$$
L_q=\frac{1}{N}\sum_{\text{校准轨迹}}\sum_{k=1}^{T}
\left(\frac{\hat q_k-q_k}{s_q}\right)^2.
$$

初始位置用于初始化，不计入误差。这里没有把位置差分生成的速度塞入损失。旧方法另加速度项 `((v̂−v)/(0.5 rad/s))²`。本轮比较中，两种方法共享命令和位置样本，初始速度都固定为零；旧 q+v 日志的后续速度才独立加噪。旧接口本身仍允许从测量速度初始化，实验脚本显式把首个速度设为零，以共享已知静止的先验。

`0.05 rad` 是残差归一化尺度，与位置噪声标准差 `0.0002 rad` 含义不同。不能把二者都叫传感器精度。两种损失包含的项数和权重不同，也不直接用 `L_q` 与旧总损失大小判优；预测结果在同一段留出位置上用 rad 报 RMSE。

每个延迟候选的 `max_nfev=30`。结果记录候选的 `nfev` 和整次拟合耗时。数值 Jacobian 还会触发额外回放，`nfev` 不包含这些额外调用；相同 `max_nfev` 不代表总计算量相等。保留每个候选的求解状态，达到预算上限的候选不能写成已经收敛。

只根据校准损失选择参数。验证轨迹用于检查模型误差，最终留出轨迹用于报告独立预测；二者都不传给拟合器。若看过留出结果后改激励或选参规则，应另建一次实验记录，不能继续把原留出称为未见数据。

## 固定实验协议

| 项目 | 本轮约定 |
|---|---|
| 对象与时钟 | 无接触单轮；dt=0.002 s；请求力矩限幅 ±2 N·m |
| 合成隐藏参数 | `I_a=0.017 kg·m²`，`b=0.105 N·m·s/rad`，`c=0.043 N·m`，`d=2` |
| 场景 | `matched`：生成与拟合模型同类；`mismatch`：生成对象额外有 Stribeck 摩擦 |
| 位置噪声 | 独立高斯噪声，标准差 0.0002 rad |
| 旧方法速度噪声 | 独立合成通道，标准差 0.002 rad/s；新拟合器看不到它 |
| 噪声种子 | 17、29、43；每个种子分别做两种场景 |
| 轨迹划分 | 两条校准各 3 s，一条验证 3 s，一条留出 3 s；每条从静止重新开始 |
| 搜索预算 | 每种方法均枚举 `d=0..4`，每个候选 `max_nfev=30` |
| 控制评测 | 四种控制臂，各跑 tracking、reversal、stress，每段 6 s |

`mismatch` 在生成对象的阻力中额外加入：

$$
\tau_s(v)=0.08\exp\left[-(v/0.3)^2\right]\tanh(v/0.05)\quad[\mathrm{N\cdot m}].
$$

拟合模型没有这个项。它用于检查遗漏低速摩擦时，拟合参数会怎样补偿，以及这种补偿能否转移到其他轨迹；不能把失配场景中的拟合参数直接当作物理真值恢复结果。

## 参数进入控制器之后

四个控制臂分别是纯 PI、标称模型前馈、位置拟合前馈，以及旧 q+v 拟合前馈。它们共用隐藏对象和 PI 增益：`Kp=0.12 N·m·s/rad`，`Ki=0.6 N·m/rad`。每段重新初始化对象与控制器，测量噪声使用配对种子。

所有控制臂仍接收独立合成速度测量。这里检验的是“仅位置辨识得到的参数能否改善速度控制”，不能把整套控制系统称为 position-only。

前馈使用当前参考速度及其解析导数：

$$
\tau_{ff}=(J_L+\hat I_a)\dot\omega_{ref}
+\hat b\omega_{ref}+\hat c\tanh(\omega_{ref}/0.05).
$$

PI 再根据当前参考与速度测量之差产生反馈力矩，并按[单轮控制实验中的规则](wheel_control_lab.md)处理积分饱和。拟合出的延迟用于轨迹预测，但这条前馈公式没有逆掉纯延迟，也没有使用未来实测状态。

速度跟踪 RMSE 比较同一时刻的 `ω_ref[k]` 和实际 `v[k]`，不能错配到 `v[k+1]`。同时查看力矩限幅比例；如果触发 30 rad/s 的速度保护而提前结束，要保留未完成状态，不能拿更短的片段宣称误差降低。力矩 RMS 的单位是 N·m，不是功率或能耗。

## 手算第一步

下面单独选一组便于计算的参数，检查时序与单位，不使用正式实验结果。令 `J_total=0.020 kg·m²`、`b=0.1 N·m·s/rad`、`dt=0.002 s`，从 `q₀=0、v₀=0` 开始，输入 0.5 N·m。设置 `I_a=0.020−0.00189225=0.01810775 kg·m²` 即可得到这个总惯量。

台架在每步开始计算平滑摩擦，此时 `tanh(0)=0`。黏性阻尼由 MuJoCo `implicitfast` 隐式处理，所以无延迟的第一步为：

$$
v_1=\frac{dt\cdot0.5}{J_{total}+b\,dt}
=\frac{0.001}{0.0202}
\approx0.04950495\ \mathrm{rad/s},
$$

$$
q_1-q_0=dt\,v_1\approx9.90099\times10^{-5}\ \mathrm{rad}.
$$

这个结果可直接用 `ActuatorBench.step(0.5)` 检查。若延迟改为两步且队列起初全零，`q₁=q₂=0`，到第三步才得到上面的位移。把显式欧拉算得的 `v₁=0.05 rad/s` 当成这里的精确答案，会漏掉隐式阻尼项。

单步位移还小于本轮位置噪声标准差 0.0002 rad。拟合依赖整段轨迹，不能只看第一步的带噪位置判断延迟；也不能把位置直接差分后当成同精度的速度测量。

## 运行与检查结果

在仓库根目录、按 [README](../README.md) 安装依赖后运行[评测脚本](../scripts/evaluate_encoder_identification.py)。下面使用自己的新目录，避免覆盖正式记录；脚本拒绝写入已存在的输出目录。

```bash
python scripts/evaluate_encoder_identification.py \
  --output results/my_encoder_identification
```

完整默认参数等价于：

```bash
python scripts/evaluate_encoder_identification.py \
  --output results/my_encoder_identification \
  --seeds 17 29 43 \
  --scenario both \
  --duration 6 \
  --calibration-duration 3
```

`protocol.json` 记录已知量与种子，`summary.json` 汇总拟合和评测。`source.json` 与 `source.tar.gz` 保留实际运行源码，`source_consistency.json` 检查运行期间是否变更；`manifest.json` 给各文件记录 SHA-256。

每组数据在 `matched_seed17/` 这类目录下。`fit_position.json` 和 `fit_position_velocity.json` 保存两种拟合的候选；位置日志与 q+v 日志分开保存。逐步预测和控制记录使用 `.csv.gz` 无损压缩，`holdout_prediction.png` 与 `closed_loop.png` 用来检查曲线，指标仍以原始记录为准。

控制臂在记录中的名称为 `pi`、`nominal_ff`、`position_ff`、`position_velocity_ff`。默认协议预计生成 72 个控制例，以及 72 行预测指标；后者包含校准轨迹上的指标，不能全部当作留出样本。

运行后先核对实际协议与日志长度，再看未参与拟合的预测误差。需要保留参数候选的收敛状态和不同种子间的变化；曲线贴合却参数波动大时，应继续检查可辨识性。闭环是否改善，要看四个控制臂在同一任务上的比较，不能由校准误差代替。

## 本轮结果

固定协议已完成，12 次拟合和 72 个控制例都有记录，未触发速度保护。下表按三个噪声种子取算术平均。每个场景内，三个种子共享同一组合成参数，只重复了传感器噪声，不能当成三个不同电机或参数总体的验证。汇总结果及原始记录入口见[正式实验记录](../results/encoder_identification_position_only/README.md)，原始数据随本轮 Git 提交保存，无需下载 v0.6.0 Release。

留出位置 RMSE 的单位是 rad，比较的是未参与拟合的整段激励：

| 场景 | 标称模型 | 仅位置拟合 | q+v 拟合 |
|---|---:|---:|---:|
| matched | 0.293601 | 0.000285 | 0.000282 |
| mismatch | 0.319744 | 0.085076 | 0.084441 |

matched 中两种方法都找回了真实的两步延迟，即 4 ms。mismatch 中两种方法却都选了四步，即 8 ms，碰到本轮搜索上界；隐藏对象的真实延迟仍为 4 ms。遗漏 Stribeck 摩擦后，较低的轨迹误差不能作为延迟恢复正确的证据。本轮保留这个结果，没有扩大搜索范围再挑一次参数。

全部 60 个延迟候选都报告求解成功，`nfev` 为 6–8，未达到 30 的预算上限；每次拟合耗时 3.70–4.57 s。连续参数没有碰到边界，但失配场景的延迟碰界。求解器成功退出只说明满足数值停止条件，不能消除这处参数错误。

速度控制的均值如下，RMSE 单位为 rad/s。“减少”按 `1−仅位置拟合均值/标称前馈均值` 计算：

| 场景 / 任务 | 标称前馈 | 仅位置拟合前馈 | q+v 拟合前馈 | 相对标称减少 |
|---|---:|---:|---:|---:|
| matched / tracking | 0.292234 | 0.015670 | 0.015673 | 94.64% |
| matched / reversal | 0.275373 | 0.020003 | 0.020005 | 92.74% |
| matched / stress | 3.641798 | 2.735800 | 2.735815 | 24.88% |
| mismatch / tracking | 0.306694 | 0.057156 | 0.056649 | 81.36% |
| mismatch / reversal | 0.282062 | 0.051427 | 0.051005 | 81.77% |
| mismatch / stress | 3.641824 | 2.726304 | 2.732995 | 25.14% |

这组对象上，位置拟合前馈降低了速度误差，但 stress 的请求力矩限幅比例增大了：matched 从 43.00% 到 55.57%，mismatch 从 43.00% 到 56.44%。普通 tracking/reversal 未出现限幅。不能只看 RMSE 就把高强度任务称为控制性能全面改善。

q+v 参考在 matched 中与仅位置拟合很接近；mismatch 下它的留出位置误差略低，tracking/reversal 的速度误差也略低，stress 则略高。本轮不支持“去掉速度信息更优”的结论。它验证的是在已知力矩尺度与初始静止等条件下，位置轨迹足以给这一个合成对象提供有用的前馈参数；低速模型失配和延迟误判仍然存在。
