# 主路线执行记录 14：保存行为价值诊断确定下一项单因素比较

第 13 阶段发现：旧 final 在四个已评估任务上加速跟踪改善、保持跟踪变差，且当前保存的评估奖励没有支持“总奖励偏好稳态超速”。因此第 14 阶段按冻结合同，读取原训练数值块并用旧 final 做一次有界 value/梯度诊断。它没有更新策略或运行机器人物理。[完整诊断与证据](../results/d1_main_route_execution_20260929_14/README.md)保留固定选择、原始梯度和独立读回。

四个训练时间等分组各有 245 个合格 64 步窗口，按预定 SHA256 排序各取 128，共 512 个。端点是同 episode 的下一条 `input_observation99[t+64]`。实际模型调用为一次旧 final 加载、1024 个 value 状态行、四次 critic backward；没有 actor 前向、optimizer、learn、save 或新物理。模型和 Adam 状态哈希前后相同，host 与独立读回均通过。

当前 final 的起点 value 均值 48.89430；原环境 reward 的 64 步折扣和加当前 final 端点 value 后，目标均值 212.93801。512 个残差全部为正；总体归一化偏差 B=0.875603、归一化 RMSE E=0.872718，末训练组仍满足预注册的广泛欠估门 U。四批 critic-only 梯度 L2 分别为 1860.57、1853.62、1850.75、1843.42，均超过强裁剪压力门 C。若仅把这些代理 critic 梯度施加原 0.5 全局 cap，计算所得系数约 0.000269–0.000271。

这些数字是**保存行为 64 步加当前 final bootstrap 的代理**。历史 PPO GAE、历史 actor 梯度和 final on-policy 真值均未保存或测量；计算出的 critic-only 系数不能当作历史 actor 更新缩小倍数。actor 与 critic 参数独立，当前证据支持检查全局裁剪标量耦合，尚未证明它导致了旧控制退化，也没有证明更改会改善机器人表现。

据此，第 15 阶段选定相同旧权重及 Adam、相同新种子和新增预算的两臂比较：原全局 clip=.5 与 actor/critic 分组各 clip=.5。该阶段另有合同，总新增训练上限 32,768 controls；含有条件新 seed 评估的总上限 63,368 controls。**它在本记录中仍是获授权、正在准备的后续实验，没有已完成的学习或物理结果。** 决策将依据真实 pre/post 梯度、实际 Adam 参数变化，以及新 seed 的完整安全、保持跟踪、力矩成本和制动成绩，不以代理 loss 替代这些门。
