# 49：展示素材与单变量候选交付

本轮交付了实际离屏片段和三个有原始轨迹的控制候选预检。三个候选均未过预注册门，不替换默认控制器；新增实验训练为零，48 归档未重跑，v27 未重绑，冻结源未修改。

| 项目 | 实际结果 | 决定 |
|---|---|---|
| wheel 展示 | flat_1p6 / yaw_1p2，各 321 PNG、16.05 s GIF；2,964,907 / 2,894,289 B | 完整 C31 状态回放，已写入 README/PORTFOLIO；不新增性能结论 |
| D1 展示 | forward_stop / turn_stop，各 241 PNG、12.05 s GIF；551,003 / 1,006,299 B | 新录制共 1,200 次推理、12,000 native steps；另有 1,200 次零物理动作回放，差异为 0 |
| 状态估计补偿 | 离线 pitch RMSE −12.62%；闭环共同完整三对跟踪 RMSE +16.84%，两臂各 4/6 跑满 | 拒绝；四个跌倒案例保留，144 场完整矩阵未运行 |
| MPC 高度权重 90→180 | 三 seed、12/12 场完整；失配高度 RMSE 125.230936→125.056052 mm（仅 −0.13965%） | 未达 ≥10% 改善门；80 场完整矩阵未运行 |
| PI 前馈倍率 1→0.75 | 三 seed、12/12 场完整；饱和减少 11.97 / 11.32 个百分点，但 RMSE +20.11% / +19.22% | 超过最多 5% 退化门；36 场完整矩阵未运行 |

状态估计、MPC、PI 分别执行 21,350、48,000、36,000 个显式控制积分子步，共 105,350。模型编译器内部原生调用没有独立计数，测试夹具另计，不能将这个合计描述为整个会话的全部物理调用。MPC 是平面教学模型，PI 是合成轮轴台架；不能将它们的数字并入 D1 全机成绩。

课程、奖励、策略仍可以作为后续单变量研究对象。[训练只读诊断](training49_diagnostic.md)核验五份完整权重，纠正 `σ≈0.139` 被称为 `log_std` 的错误，并重算合池 RMS。现有记录不能证明探索噪声导致 seed 摆幅，也不能否定课程或奖励调整。标准差减半只是待判定问题；没有启动单 seed 排名或多变量训练。

## 验证与失败项

- 新候选测试 23 项、新展示工具测试 16 项通过；`ruff check src tests examples scripts` 通过。
- wheel 全量测试第一次因未加载已有 `.local-deps` 出现 29 项收集错误；第二次使用现有依赖后，在约 40% 被 `systemd-oomd` 整组终止。两份记录均保留，第二次标记 INCOMPLETE、完成数未知，没有提高 2/3 GiB 限额或续跑该进程。完整远程 CI 必须按最终提交 SHA 单独核验，局部通过不代替它。
- D1 本地全套测试 2,804 passed / 1 skipped；其新增展示测试 7 项也单独通过。合同静态检查 32/32 通过，回执确认零积分、无需模型；全部检查继续使用已有零模型、零物理测试保护。
- v27 清单 SHA 仍为 `d3c38429362e82745179f2c526b2ee52d805526df390d52346c805e5a51fff09`；其中 928 个仓库内冻结文件 SHA 全部匹配。原冻结入口的外部库漂移仍未解决，所以 wheel 展示采用完整归档状态，不借渲染绕过策略启动准入。
- 候选性能失败与执行 partial 分开记录：四个跌倒是完成评测矩阵中的失败回合；MPC/PI 的 24 场均完整，但性能门不通过；全量测试的 SIGKILL 是独立的验证中止。

所有本机重任务串行，使用 Nice10、单核/单线程、MemoryHigh 2 GiB、MemoryMax 3 GiB、swap0；准入需有效可用内存连续满足 4 GiB，运行保留 2 GiB。既有失败、partial 和 PNG 均保留原目录，不覆盖或续跑。每次资源回执和来源哈希见[交付机器记录](../reports/optimization49_delivery_20261022.json)。
