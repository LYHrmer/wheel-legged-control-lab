# B22 47：奖励形状效应的 seed 复制（设计）

状态：**COMPLETE（形状效应未获证实）**：仅换 seed，β=0 镜像从0.9324摆动到0.8586，分离规则不成立；见[结果](b22_seed47_results_20261020.md)。本修订不提出新奖励、不改任何门槛，只回答一个问题：**44/46 之间 0.9024 与 0.8834 的差，是奖励形状的效应，还是单次训练的噪声。**

## 一、为什么必须先做这一步

42–46 每一臂都只训练一次，且都用 PPO seed 201011。0.8834（46 镜像）、0.8976（42 权重+镜像）、0.9024（44 raw）这些数之间的差，从未与 seed 间波动比较过。同一套原六任务先后被用于选择 42→43→44→45→46 的下一步，封存集也已在路线 A 用掉。因此 46 的"目前最好"目前只是**单项观察**，不能作为设计决策的依据。

**主矛盾是"没有噪声底、没有干净确认集"**；在这个矛盾解决之前，继续增加新奖励臂，只是在噪声里挑数。

## 二、设计

| 项 | 值 |
|---|---|
| 臂 | `ffyaw_s21`（α=8、β=0）与 `ffsse_s21`（α=8、β=8） |
| 新 seed | 201021（`seed` 与 `ppo_seed`） |
| 固定项 | 完整 B22 与 Adam、FF=3.9 前馈基线、`yaw_emphasis` 课程、`command_seed` 201002、`measurement_seed` 201003、32768 拍 |
| 预算 | 65536 controls / 327680 normal-native / 4 compiler-native |
| 资源 | 4 GiB 有效可用内存持续 10 秒启动、运行保留 2 GiB、整组 2/3 GiB、无 swap、Nice10 单线程串行、不重试不续跑 |

两臂在**同一 seed 内配对**：初态、初始 policy/Adam 状态、首 1024 拍非奖励数据必须逐位一致；跨 seed 不做这种相等要求。

**一个已核实的实现要点**：`train22.py` 的 PPO 种子取自 `spec['training']['ppo_seed_by_stage'][stage-1]`，不是 session 的 `ppo_seed` 字段。若只改 session 而 worker/reader 仍把该 spec 项写成 `201011`，两臂仍会用旧种子，复制会静默失效。本修订在 worker 与独立 reader 中都改为 `[201001, session['ppo_seed']]`，并加了源码级回归测试。

## 三、预注册的判定规则（跑之前定好）

用已有的 seed 201011（44 `ffyaw`、46 `ffsse`）与本轮 seed 201021 合成 n=2；若需要第三个 seed，再开 48。

- **主判据（分布无关）**：`max(ffsse 各 seed 的合池比) < min(ffyaw 各 seed 的合池比)` 才算"形状有效"。n=2 时同样适用。
- **辅助**：报告每个臂的均值与极差；n≥3 时附 Welch 单侧 t 检验。
- **不采用的规则**：n=3 时的 2σ 规则。样本标准差本身相对不确定度约 50%，2σ 会系统性误判。
- **主结果口径预先固定**：镜像合池比为主（部署形态），raw 为次；两个都报，不允许事后挑。
