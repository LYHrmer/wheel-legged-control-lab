# 后续 A/D 主路线：连续速度任务与 RL

状态：Astra 制定的下一阶段设计，尚无新控制器、训练或仿真资格。整体目标仍是“稳定直行 → 可靠越障 → 提高速度”。B22 的固定直行已有 1.60145 m/s 仿真证据；本方案解决仍很慢的 A/D 横移，两者不能混为同一速度指标。

C31 的侧移 RL 额外收益很小，C32 保存数据诊断支持旧价值网络数值欠拟合，C33 固定时序缩短未达提速门，[C34 速度补偿](ad_lateral_tracking_20261003.md)则因误差和保持率失败而停止。继续训练同一种微小参考残差，尚无充分的速度控制权限依据。

## 为什么改变任务

旧控制器按四腿串行执行，每腿至少包含 0.12 s 卸载、水平五次曲线和 0.15 s 加载；下降后的接触切换还要求超过 `0.4 × 0.26 = 0.104 s`。在当前 `distance_scale=1`、自适应摆腿、水平峰速 0.16 m/s、步长 `D ≤ 0.04 m` 和阶段顺序下，即使把身体移动、抬脚等待和接触停留全部视为免费，也有

```text
T ≥ 4 × [0.12 + 1.875D / 0.16 + 0.104 + 0.15]
D = 0.04 m 时：T ≥ 3.371 s，D/T ≤ 0.01187 m/s
```

这是由[旧 Fast 控制器](../scripts/d1_fast_side_step.py)阶段和参考公式得到的条件上界，不是机器人动力学极限。真实稳定、接触与净空约束还会增加耗时；改变步长、脚速或重叠权限后也不能继续引用该界作为新任务证明。它说明只让身体在原单腿脚相期间继续移动，仍不足以达到拟定的最低工程目标。

下一任务改为持续跟踪横向速度：建议最低工程目标 **0.02 m/s**，发展目标 0.03–0.04 m/s，约为当前名义 0.0032 m/s 的数倍。这些是待验证目标，不代表已实现，也不替代用户对操作流畅度的验收。

## 输入和控制权限

持 A/D 给出有时效的横向目标速度，由一个侧移控制器连续更新身体与足端参考，不在每个 30/40 mm 边界复位或交还 B22。松键、A+D 同按或停止命令先把目标置零，完成安全落地与制动；反向先停稳，再重新准入。失焦、输入过期和异常取消分别记录。四足承载停稳后，才在正确的控制边界恢复 B22。

旧 B22 的 99 维编码器拒绝非零横向速度，因此使用独立侧移意图通道，保持 B22 权重冻结。不能把旁路侧移控制算成 B22 已学会横移。

首先设计持续身体速度参考及显式接触相位调度，评估对角两相交替、无腾空的固定控制可行性。摆动对象从单腿改为明确的一组腿，这是新增接触权限。若在原执行器和物理限制下不可行，记录阻断因素，再评审步长、脚速或三维足端轨迹；不回到反复的小参数扫描。

## 保留约束与需要重新验证的规则

保留同一模型、100 Hz 控制与 500 Hz 原生积分、完整逐子步记录，以及姿态、高度、关节范围和速度、电机力矩、非轮碰撞、有限 IK/力分配、摆动轮整体净空和接触证据。新参考不能通过放松这些限值取得速度。

原三足准静态准入、每腿前的身体停走、固定四腿顺序和一次 30 mm 宏属于需要显式替换的规则。两腿支撑不能继续用三角形静态裕度证明资格；新的最少承载轮数、允许摆动组合、实际接触反力、失接触处理和无腾空条件必须在下一有界合同中逐项定义。

原 `dynamic_margin` 使用 COM 减去参考加速度项，是代理量。它不是真实 CoP 或实测 COM 加速度，也不构成新连续步态的稳定性证明。所有安全结论限于实际检验的仿真条件。

## 固定控制、RL 与交付顺序

1. 冻结新输入、参考与接触接口，执行能检验数倍提速可行性的最小固定控制实验。新的步数、模型调用和停止规则另立有界合同，旧预算不转用。
2. 在相同权限下建立有速度反馈、落点调整和触地反馈的强固定控制器，利用开发集确定参数后冻结，预留新条件用于评价。
3. 只有固定可行性通过且还存在有用的状态相关决策空间，才启动真实 RL。候选动作是接触相位推进与落点、身体参考残差；策略不能控制仿真积分、删除接触门或提高力矩限制。价值网络按完整 episode 划分检验真实 return 拟合，不凭增大网络就假定欠拟合已解决。
4. 在同一预先冻结的命令阶梯上，比较各算法自身最高的全部合格速度；每一档都要求双向持键、停止、反向、误差、保持、成本和 native 安全通过。拟议 RL 贡献门是在新保留条件下比同权限强固定对照高至少 20%，且达到最低工程速度；确切门槛在执行前冻结。跟踪同一速度上限时，超调不算提速，误差或稳定性收益另行报告。
5. 把已合格控制器接入 GUI，验证持键、松键、反向、失焦和输入过期。单场 headless 结果不等于键盘操作交付。

当前未启动这一新任务的训练，也未取得连续侧移资格。实际决策和原始设计保存在 [C35 设计记录](../results/d1_ad_velocity_reference_20261003/design35/continuous_velocity_main_task35.md)；C34 最终结论以独立报告为准。
